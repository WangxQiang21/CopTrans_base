# 模式决策与轨迹规划：算法路线比较

## 1. 结论

模式与几何轨迹在狭窄泊车里是耦合决策：同一局部位移能否通过，取决于选择的 A/O/S 运动学；选了某个模式，又会改变下一段可达的位姿与方向。因此，“先用二维规划器定死一条路径，再在路径上贴模式”不应作为最终规划器。

推荐 expv3 的算法目标为：

```text
二维拓扑搜索（只负责产生多个路线/走廊初值，不决定最终运动）
                 ↓
每个候选走廊内做模式二进制变量 + 连续车辆中心位姿/控制的联合空间优化
                 ↓
固定解的连续细化 / 时间化 → 独立 OBB 连续扫掠验收
```

即“先有拓扑初值，但不先承诺模式或精确路径；真正的模式与轨迹在走廊优化中联合决定”。它比全地图多模式 Hybrid A* 更能控制组合规模，也比路径先定、模式后贴更少受前端单一路径偏置。若可用求解器或运行时间不允许一次性解完整混合非线性问题，可用有限的模式序列主问题 + 固定序列连续优化子问题迭代逼近，但每轮必须允许改变模式序列和几何，而不是把第一次图搜索结果锁死。

## 2. 相关算法及其适用边界

| 路线 | 决策和规划的关系 | 合理之处 | 对当前项目的主要问题 | 判断 |
|---|---|---|---|---|
| **多模式 Hybrid A\***（本地论文 06；Yang 08 的图搜索前端） | 模式、位姿和动作在搜索扩展时同步决定；连续运动通过离散 primitive 近似 | 模型与碰撞可逐边验证；天然保留倒车、模式和换模位置；能 anytime 地找到可行解 | 状态/控制/方向/前序动作标签乘积大；分辨率和 primitive 集合决定可达性；每条边要做扫掠；代价影响扩展次序，预算到期可能无解；Yang 的 QP 后端通常固定前端序列，不能纠正错误的模式选择 | 保留为基线和有界 fallback，不作为唯一主规划器 |
| **二维 A\* 后再分段选模式** | 先定路线，再选择模式；决策与规划主要分离 | 快、简单、ROS 接入容易；适合作为拓扑路线或 corridor 初值 | A* 折线没有航向/曲率；单一路线可能在车身可行性或终点航向上不合适；后选模式不能跨越另一条拓扑路线，也不能修改门之间几何 | 只能作 warm start；若不回到联合优化，不足以解决核心问题 |
| **拓扑预览/模式剪枝 + Hybrid A\***（Zhu 16） | 用通道宽度、转折和目标预览提前减少模式扩展，剩余部分仍联合搜索 | 有针对性地减少不必要扩展；比纯粹调整 switch weight 更结构化 | 若预览规则硬删模式，会删除本来可行的特殊 maneuver；阈值和分类规则可能成为隐式状态机 | 只借用能由运动学/车身几何证明的硬剪枝；其余只调候选顺序或松弛界限 |
| **粗搜走廊 + MIP 联合优化**（Chang 2024、Chang 2026） | 粗搜给引导路/走廊/初始模式；优化器内用二进制模式变量和连续位姿/控制变量，共同求路径与模式序列 | 正面处理“模式先选还是路径先选”；代价与运动学约束可同时影响两个决策；不需要在全地图每格扩展每一种模式 | Big-M/二进制组合增大计算量；真实 A/O/S 方程含三角非线性，精确形式是 MINLP；改成 PWL/MIQP 会有近似误差；单个 corridor 会丢失其他 homotopy；STC/特征圆不能代替最终 OBB sweep | **最符合问题本质，建议作为 expv3 目标架构**；先限于小规模、多个候选 corridor 和独立验收 |
| **模式主问题 + 固定模式 NLP 子问题（逻辑分解/交替迭代）** | 主问题改模式序列，子问题连续优化位姿/控制；子问题失败或代价差时反馈 cuts/邻域变化 | 可复用 expv2 固定模式 optimizer；不用立刻把所有三角模型改造成 MILP；可限制每轮计算量 | 若 master 只保留少数规则生成序列，会漏解；若每轮只做局部换模，会卡在初始模式序列附近；没有有效下界/cut 时不保证联合最优 | 适合作为首个可落地 solver 原型，但必须多初值、允许全段重排，并报告非全局最优 |

论文结论需要谨慎解读：本地 11（Chang ITSC 2024）明确采用改进 A* 生成粗路径，再用含二进制模式变量和连续状态的 MIP 同时优化模式与路径；其论文将非线性关系用分段线性函数近似，并使用 Big-M 与 Gurobi。因此它证明了联合建模可行，不证明原始精确 4WIS 几何本身是线性 MIP，也不代表同一计算量可直接移植到 Ranger。2024 论文原文可从 [IEEE DOI 页面](https://doi.org/10.1109/ITSC58415.2024.10920196) 定位；本地全文为 [论文 11](../papers/11_Chang_4WIS_Parking_Mode_Decision_2024.pdf)。

本地 13（Chang 等，Spatio-temporal decoupling）把粗 A* 明确定位为生成 corridor、Big-M 界和整数初值；空间层再联合优化离散模式与连续几何，时间层另做分段轨迹和换模瞬态。它与当前仅需几何轨迹的阶段吻合，但 corridor 会限制可搜索的同伦类；其状态方程含航向相关非线性项，移植时必须核实论文的离散化、约束编码及求解器支持，不能把“称为 MIP”直接等同于本车精确模型已有线性混合整数实现。参见[出版方文章页](https://www.sciencedirect.com/science/article/pii/S0020025526006067)及本地[论文 13](../papers/13_Chang_Spatio_Temporal_Decoupling_2026.pdf)。

Yang 2026（本地 08）是“多模式图搜索 + 分模式段 QP”：模式序列主要由前端搜索决定，QP 优化已分好的段。因此它比纯 2D A* 后贴模式更联合，但若前端代价或离散动作选错模式，固定序列 QP 不能真正换模纠错。Bao 2025（本地 06）是 arXiv/会议投稿稿，状态显式含 `(x,y,θ,m)` 并设计多模式 RS 和切换代价；适合作搜索基线，不应把论文报告视为对本项目参数/模型的保证。[arXiv 原文](https://arxiv.org/abs/2509.06115)。Zhu 2026 的方法报告以 PSP 拓扑剖面和动态剪枝减少扩展，但它仍是模式搜索，不是路径—模式的数值联合优化；可参考[期刊原文](https://www.mdpi.com/2032-6653/17/7/335)。

## 3. 为什么现在的多模式图搜索会“很简单也搜不出来”

需要区分“没有可行轨迹”和“预算内没找到”。在有限图上，若所有边代价有限且非负、搜索没有提前终止、闭集没有错误合并且候选原语覆盖可行运动，那么单纯改变代价一般只改变先后顺序/选出的解，不会把图中的可行路径删除。实际 Hybrid A* 会因为以下原因表现为“搜不出来”：

1. `(x,y,θ)` 量化和动作步长使必要的狭窄连接没有落到栅格/终端容差内；
2. 同一量化 key 合并了控制历史不同、未来可达性不同的节点，或状态维度反过来过度细分；
3. 模式剪枝、有限终端连接族、过早关闭目标附近状态删掉了关键动作序列；
4. 扩展分支数近似乘以模式数、方向数和控制数，碰撞 sweep 让每个扩展昂贵；固定预算在正确分支被弹出前耗尽；
5. 非可采纳/过强的启发只改变队列顺序，但配合预算上限会造成特定分支长期得不到探索；
6. 目标航向、换模、倒车或转向代价标度不一致，搜索容易偏向只用 A 或只用某一种模式，得到低质量但“成本便宜”的结果。

所以代价调试很重要，但不是“代价不合适就数学上无解”。无解必须同时检查动作集、碰撞连续性、终端容差、剪枝、状态 key 和预算；只调 switch weight 不能解决结构性漏解。A* 的最优性也只相对于其离散图和代价成立，不是连续车辆规划的全局最优。

## 4. 推荐的联合空间优化模型（Demo 范围）

### 4.1 上层只做拓扑/凸域初始化，不提交最终路径

对点占据图跑快速 2D A*，并为困难目标保留若干低代价、不同拓扑路线；经可视线简化后构造 corridor/STC。二维路线不包含可执行姿态，也不决定采用哪种模式。走廊至少覆盖车辆中心可行区域；优化时用覆盖车身的 feature discs / 分段凸域作约束，最终仍由 OBB 连续扫掠作裁判。一个 corridor 优化失败，允许换 corridor 或扩展/重建，而非仅放宽碰撞约束。

### 4.2 在走廊内同时优化模式、位姿和连续控制

令 `q_k=(x_k,y_k,θ_k)` 为车辆中心位姿，`α_{k,m}∈{0,1}` 为模式变量，满足 `Σ_m α_{k,m}=1`，`m∈{A,O,S}`。每个区间只启用所选模式的精确传播：

```text
A: θ[k+1] = θ[k] + κ[k] Δs[k]
   c[k+1] = integrate_exact_A(c[k], θ[k], κ[k], Δs[k])
   |κ[k]| ≤ 1 / R_min

O: θ[k+1] = θ[k]
   c[k+1] = c[k] + Δs[k] [cos(θ[k]+φ[k]), sin(θ[k]+φ[k])]
   |φ[k]| ≤ π/2

S: c[k+1] = c[k]
   θ[k+1] = θ[k] + Δθ[k]
```

选择变量是模式 `α` 和连续量 `(q,Δs,κ,φ,Δθ)`，不是先定模式序列再单独找轨迹。硬约束包括起终点位置/航向、模式方程、车辆限制、走廊和换模合法性。Spin 的位置不动但需整段旋转安全；模式转换不能通过“给碰撞 slack”处理。可以加入最小模式段长度/相邻区间约束，避免零长度闪切，但阈值需能由底盘切换语义解释。

### 4.3 目标函数与“少频繁打方向、大方向交给 Spin”

先用带量纲的估计时间，再加低权重质量正则项：

```text
J = Σ_k [ L_AO[k]/v_ref + |Δθ_S[k]|/ω_ref ]
    + λ_mode N_mode_switch
    + λ_gear N_direction_switch
    + λ_TV Σ_A |δ_v[k+1]-δ_v[k]|
    + λ_κ Σ_A κ[k]^2 L_A[k]
    + λ_clear Σ_k clearance_risk[k]
```

其中目标航向是端点约束，不应只作为弱权重；因此目标需要转多少角会直接影响所需 A 曲率、Spin 角度和最终可行性。`TV` 抑制反复调方向，曲率能量抑制长时间紧弯，模式切换项避免为了很小几何收益不断切换。Spin 以估计角时间收费，只有它比 A 弧更快/更低代价、且旋转 footprint 全扫掠可行时才会胜出。不应设“曲率超过某阈值必用 Spin”。

代价权重需通过多场景 Pareto/消融标定，并保留分项日志。一个场景只输出 A 不代表算法错：应检查 Spin/O 是否可行、总估计时间和转向变化是否确实更差；若用户希望减少切换，需让切换时间/成本与 mode-specific travel time 在同一量纲，而非硬性要求出现多模式。

### 4.4 规模控制与实现路线

精确模型带 `sin/cos`，二进制乘连续变量和旋转碰撞约束，不是直接可解的小型 MIQP。合理路径是先沿粗路线建立紧 trust region、只在关键站点设置少量模式二进制变量、对运动学做局部线性化/PWL 或使用小规模 MINLP；对线性化结果重放精确方程并 sweep，不通过就缩 trust region/重线性化。准备多条 topology corridor 防止单一路线导致局部不可行。大场景再研究 branch-and-bound、logic-based Benders 或分层候选序列求解。

推荐落地顺序：

1. 先把当前 Hybrid A* 改成任何已验证可行解尽早返回的有界基线，记录耗时、扩展、失败原因，不通过增大权重“救活”搜索。
2. 建 2–5 条 2D 拓扑 corridor 作为初值/搜索域，不输出为轨迹。
3. 复用 expv2 的固定模式连续优化器作为联合优化的**子问题和首轮 incumbent 生成器**，但不能把其序列固定当最终决定。
4. 增加模式变量和转移代价，使优化器能在 corridor 内插入、删除、替换、移动 A/O/S 段；从多个初始序列启动，失败时由 IIS/约束冲突或明确验碰原因产生局部 no-good/补候选，再解其他序列。
5. 当这个交替/分解原型稳定后，评估将有限 mode binaries 纳入 corridor NLP，构成 sequential MIQP/MINLP。每轮都用精确 A/O/S 模型重放及 OBB sweep 认证。
6. 在 RViz 显示 corridor 初值、联合优化后的 mode sequence、各代价分项及 rejected-candidate 原因；轨迹合同仍为带时间的车辆中心 `(t,[x,y,v,θ])`。

步骤 3–5 是逐步落地策略，不应把阶段性“交替优化”宣传成全局联合最优。完整混合整数方法的价值在于允许模式和几何相互纠正；工程实现若没把离散 mode 变量真正放进优化/主问题，它就仍然是“先搜索选模式、再固定模式优化”。

## 5. 对上一版架构建议的修正

上一版提出的“2D A* → 走廊门候选图 → Dijkstra 选模式序列 → 固定序列优化”降低了全域搜索规模，但 Dijkstra 已先锁定 mode sequence，固定模式优化无法再选择别的模式，仍未彻底解决决策—规划耦合。它可保留为缺少混合整数求解器时的可行候选生成 baseline，不再作为最终推荐的联合算法。新的主线以走廊内 mode/trajectory 联合优化为目标，二维路线只提供拓扑和信赖域。

## 6. 当前代码验证结论

已在 ROS 优化节点接入两个互补入口。默认启用的是有界等效模式主问题：对粗解按控制/模式事件压缩 knot，逐边用精确 A/O/S 模型拟合相邻中心位姿，端点误差超过 3 mm 的模式丢弃，再按配置的共同 cost 用 beam 保留少数候选；每个候选交给固定模式连续优化器，最后统一比较代价。这样模式序列确实能被 cost 改写，但目前只覆盖“同一几何段可由另一模式表达”的候选，不会凭空生成新拓扑或大幅改变区段几何。另有完整 `joint_refine` Bonmin MINLP 入口，可同时优化 mode one-hot、前/倒方向、轨迹节点及模式控制；它仍是实验功能，Demo 配置默认关闭。所有候选都要精确重放并通过终点容差、整车 swept-SAT 和时间化轨迹验碰。

等效模式主问题已有端到端回归用例：合成“直行—横移—Spin”粗解中，它把首段直行 A 精确替换成 O，得到 O/O/Spin；固定模式连续优化后仍通过 swept-SAT，模式切换从 2 次降至 1 次，共同代价也低于原序列。这是一个可用的泛化机制，但它的候选集被原粗解锚点限制，无法解决“替代模式需要换一条几何路径”的情况。完整 MINLP 方面，事件 knot 压缩后单段 1 m 直线约 0.3 秒、单 knot Ackermann→斜移替换约 0.5 秒可解；A→Spin 等多 knot 例子仍会达到 NLP 迭代上限，A/O 混合例子还触发 Bonmin 内部错误，设置的 time limit 也没可靠约束整次调用。已增加初始约束残差诊断，A→Spin 示例的粗解初始点本身满足模型约束，故当前证据更指向 Bonmin 内层 NLP/分支求解稳定性，而非单纯的初值不可行。MINLP 因此不放入默认 ROS 回调。下一步应把等效模式候选扩展为局部几何候选：围绕少量关键锚点生成替代模式段并调用连续子问题，再按失败原因补充候选；仍保留多 topology 初值，完整 MINLP 继续单独诊断。
