# expv3 好轨迹评价规范与 Cost 设计

规范版本：`trajectory_quality_spec_v1.2`（2026-10-10，更新双向代价、速度合同与归一尺度）  
建立日期：2026-10-08；最近修订：2026-10-10  
适用对象：单车 4WIS 的 A / O / Spin 模式与路径联合规划。

当前合同要求：在合理增加时间和路程的范围内提高整车净空、减少控制调整；稳定 A、O 与必要 Spin 共同竞争；用户指定巡航目标 2.0 m/s、横向加速度上限 2.0 m/s²。同模式连续转向不能因几何采样点停车，只有真正切换 A/O/Spin 才静止重配置；档位变化的速度经过零，不额外插入等待。倒车是可行候选，以软成本鼓励少倒车并尽量安排在后段，极端任务允许提前或全程倒车。方向不能先分阶段硬筛后再比较质量。

本文是核心重构的评价合同。R01/R02 已实现其中一部分，具体实现和验证范围见 [12_核心重构R01_实现与验证.md](12_%E6%A0%B8%E5%BF%83%E9%87%8D%E6%9E%84R01_%E5%AE%9E%E7%8E%B0%E4%B8%8E%E9%AA%8C%E8%AF%81.md)，不将本文所有要求视为已经完成。现有 `sequence_cost()` 和 `v_demo` 用于历史基线，不能直接当作本规范的完整评价器。

## 1. 基本原则与范围

1. 先定义候选是否可接受，再比较可接受候选的质量。
2. 模式组合、切换位置、切换姿态和段内几何均属于规划决策；粗解只提供初值和引导。
3. 所有初解来源、候选生成器和优化后端使用同一最终评价合同。后续学习型初解也适用；本阶段不设计强化学习训练。
4. 整车碰撞、车体净空、运动学、终点、执行时间和控制变化的定义必须跨阶段一致。
5. 用物理量描述行为，不以原语数量、采样点数量或地图名称代替质量指标。
6. 权重、阈值和限额按版本统一配置。禁止根据地图编号写模式规则、切换模板或专用权重。
7. 求解器状态、局部 NLP 失败、模型目标与最终轨迹质量分别报告。
8. 完整质量排名要求候选经过有约束的时间规划。缺少动态信息的路线只能作几何候选。

## 2. 三类要求

| 类别 | 内容 | 处理方式 |
|---|---|---|
| 硬约束 | 碰撞、方向策略、运动学、终点、速度/加速度/转向能力 | 不满足则不进入完整合格候选池 |
| 轨迹偏好 | 通行余量、曲率与变化、稳定 O、少无效调整、执行时间与路程 | 统一 cost 和成对偏好验收 |
| 求解性能 | 首解时间、总时延、固定预算成功率、质量随时间的变化 | 求解预算与独立性能表 |

硬约束不得用有限罚分替代。`J_total` 不包含机器运行耗时；真实行驶和重配置时间属于轨迹 cost。

## 3. 输入、输出与统一坐标

### 3.1 固定任务输入

每个任务在求解前冻结：

- 地图栅格、占据/未知区域策略、地图分辨率与原点、缩放比例、地图哈希；
- 车辆尺寸、运动学和能力参数、碰撞缓冲定义；
- 以车辆中心表示的起点和目标位姿；
- 终点位置/航向容差、起终点速度要求；
- 动态能力 profile、cost profile、数值容差；
- 总求解预算、随机种子及代码版本/哈希。

当前车辆参考尺寸：长 `0.738 m`、宽 `0.500 m`、轴距 `0.494 m`、轮距 `0.364 m`、A 最小转弯半径 `0.810 m`。后续参数以实际加载的车辆 profile 为准。

终点容差来自任务合同，不得在候选之间变化，也不得因某种模式不好求解而放宽。当前 N01–N06 manifest 的 `0.16 m / 0.14 rad` 是已有任务容差，不能宣称它等于实车泊车精度；新任务如采用更严格精度，需统一建立新的任务版本。

### 3.2 可评价的轨迹表示

完整轨迹至少应提供：

\[
\tau=\{t,q(t),m(t),u(t),v(t),\omega(t)\},\quad q=(x,y,\theta).
\]

另保存模式/控制段边界、重配置阶段、速度与加速度、控制变化率，以及用于验证的精确运动学描述。轮级评价启用后，保存四轮转角和轮速及其变化率。

只提供离散 `[x,y,theta,v,mode]`、没有控制与插值合同，不能充分验证正向、O 角度调整或动态可执行性。允许用伴随评价 JSON 保存补充信息，本规范不要求本轮修改 ROS 消息。

### 3.3 模式段与连续节点分离

- A 模式段允许包含多个连续曲率节点，不要求全段为一条恒曲率圆弧。
- O 模式段默认具有恒定车体航向和恒定斜行角；增加位置节点不新增调角机会。
- 需要改变 O 斜行角时，必须显式表示为控制重配置或经过认证的连续过渡。
- 相邻同模式段如控制等价且能精确合并，应规范化合并；合并不得改变轨迹或破坏安全。
- 几何节点细化用于表达精度和验碰，不能自动增加模式切换事件。

## 4. 硬约束与合格等级

### 4.1 整车安全

令 `B(q)` 为实际车身外形，`B_safe(q)` 为按同一缓冲规则扩张后的外形。全程包括平移、旋转、停车重配置和模式过渡：

\[
B_{safe}(q(t))\cap O=\varnothing,\quad t\in[0,T].
\]

地图外及不允许通行的未知区域按占据区域处理。不得用中心点安全代替整车安全。

当前 `collision.margin=0.04` 的代码含义是长、宽各增加 `0.04 m`，各车身面向外扩张 `0.02 m`；不能在报告中误写为每侧 `0.04 m`。实现其他缓冲形状时必须建立新 profile，并保持候选/基线一致。

精确动作采用独立整车 swept-SAT。当前探针的 `5 mm` 最大角点采样尺度和后端 `2.5 mm` 尺度作为已知检查配置记录；最终验证必须包含样本之间的安全覆盖或相应膨胀上界。仅有离散样本 PASS 不构成任意连续插值的证明。实际发布的插值轨迹必须重新检查。

### 4.2 双向候选与倒车偏好

- 正向、反向及混合档位 A/O/Spin 候选进入同一个质量排序；不以“已经有正向可行解”作为屏蔽 O 或反向提议的门槛。
- 可通过统一成本偏好较少倒车、少换向和较晚倒车；这些都是偏好项，不得令安全、终点、模式可达性等硬约束失效。
- 极端窄道、掉头空间不足等任务允许提前倒车或全程倒车。报告有符号速度、反向长度、换向数和提前/延后指标，不能因全程反向标签自动判 INVALID。
- O 的 `phi` 仍限定为 `[-pi/2,pi/2]`，方向由带符号的进度/速度表示；不能把 `phi=pi` 与正速度作为倒车的另一种编码。
- 反向几何仍需满足 O 斜移角、速度符号、扫掠、运动学和终点合同；不能把 O 的 `phi` 与速度方向作错误组合来伪造前进。
- `TimedPoint.v` 是带符号的平移路径进度速度；逆向段必须为负并具有受约束的减速、停车和加速。独立检查速度符号与车体朝向/位移投影的一致性；侧移的投影允许为零。
- 不得翻转目标航向、重标记负长度或交换车辆前后端来伪装正向到达。
- Spin 正负角分别表示左右旋转，允许；Spin 中心平移为零。
- 数值零附近使用版本化容差，不得用容差掩盖有物理意义的反向距离。

倒车偏好应以车辆实际弧长进度计算，使用连续衰减，不能靠毫米级前进前缀绕过，也不应诱发为了拖延倒车而绕远。记录前进/倒车距离、首段反向进度、提前反向航向调整和换向数。不得要求每一步欧氏目标距离都下降：绕障碍可能需要暂时远离目标。

### 4.3 运动学与终点

- 用车辆中心的 A/O/Spin 方程精确回放，与发布轨迹保持同一运动语义。
- A 的曲率及轮角不超过能力范围；当前几何曲率上限为 `1/0.810 m^-1`。
- O 段车体航向恒定；未经建模的动态模式不得冒充 O。
- 模式边界的位置和车体航向连续。
- 起点一致；终点位置和最短角差分别满足冻结的任务容差。
- 路径优化与最终检查使用同一目标定义；终点误差单独报告。
- 求解模型约束残差按位置、角度、控制等类型和单位检查；整数变量须满足对应域要求。

历史模型残差 `1e-5` 收益审阅线继续用于旧实验归因。重构后不得对混合单位残差只给一个无单位最大值；须保存各约束类别的容差和最大违反量。精确扫掠不接受求解器的小碰撞残差。

### 4.4 动态可执行性

完整轨迹必须满足已声明的：

- 平移速度上限及加速/制动限制；
- Spin 角速度、角加速度限制；
- 转向角和转向变化速率限制；
- 起终点速度和边界状态要求；
- 若 profile 启用 jerk 限制，则满足相应平移/角运动 jerk 限制。

所有上限必须有限、来自同一能力 profile。可使用明确标为仿真的研究 profile，不能把它称为已标定的实车能力。不得直接把 `v_demo=omega_demo=2.0` 当作真实能力。

缺少动态参数或检查结果时，动态状态为 `UNCHECKED`，不得填零代价、默认 PASS 或宣称完整可执行。

### 4.5 合格等级

| 等级 | 定义 | 可使用范围 |
|---|---|---|
| `INVALID` | 任一已检查硬约束不满足 | 失败诊断，禁止作为最终合格结果 |
| `GEOMETRY_VALID` | 方向、精确几何运动学、终点、整车扫掠通过，动态未完整验证 | 初值和几何研究结果 |
| `FEASIBLE` | 几何和声明的动态约束全部通过 | 完整轨迹候选池与最终质量比较 |
| `PREFERRED` | FEASIBLE，且在同任务/同 profile/同预算的候选比较中获选 | 相对更优的轨迹，无全局最优保证 |

`PREFERRED` 不等于“最小净空超过任意固定阈值”，也不代表整个地图的全局最优。窄通道可以产生 FEASIBLE/PREFERRED 路线，但必须报告其低余量事实。

## 5. 净空：用整车余量评价通行鲁棒性

### 5.1 距离定义

`d_body(q)` 为真实车身到占据区域/地图边界的最小欧氏距离，`d_safe(q)` 为缓冲车身到这些边界的距离。分别记录；质量项使用 `d_body`，安全门槛使用 `B_safe`。

距离计算须覆盖完整车身，包括边和角，不可只检查中心或少数不带覆盖保证的 feature 点。ESDF/feature-disc 可以作为优化代理，但最终报告须注明代理类型，并由统一外形距离评价器复核。

### 5.2 希望净空与饱和代价

初始希望净空取 `d_pref = 0.20 * vehicle.width`，当前车宽对应 `0.10 m`。它是质量偏好，不是额外通行硬门槛；修改必须发布统一 profile 新版本。

\[
\rho(d)=\left[\max\left(0,\frac{d_{pref}-d}{d_{pref}}\right)\right]^2.
\]

净空达到 `d_pref` 后该项为零，不继续奖励离障碍更远。低于希望净空的安全窄通道仍可参与比较。

### 5.3 沿轨迹累计与瓶颈

为覆盖 Spin，定义几何积分测度：平移时 `dmu=ds`，原地旋转时 `dmu=r_body*abs(dtheta)`；`r_body` 为车身外接圆半径。静止的重复采样点不重复累计几何代价。

\[
J_{clear}=\frac{1}{L_0}\int_\tau\rho(d_{body}(q))d\mu
+0.5\max_{q\in\tau}\rho(d_{body}(q)).
\]

累计项区分长期贴边与短窄口，峰值项记录最危险瓶颈。积分必须使用物理步长；不得对每个采样点简单求和。

必报：`min_body_clearance_m`、`min_safe_clearance_m`、低于 `d_pref` 的平移长度和占比、Spin 最小净空、`J_clear`。对真实通行成功概率的主张需要额外扰动/跟踪实验，单一净空值不等于成功概率。

## 6. 路径形状与控制调整

### 6.1 平移路径曲率

记平移运动方向为 `psi`，路径曲率 `kappa_path=dpsi/ds`。A 段与其中心曲率一致；稳定 O 段为零。Spin 的路径曲率不定义，不纳入平移曲率 RMS，也不能赋零值稀释指标。

\[
J_{shape}=\frac{1}{L_0}\int_{moving}
\left[\left(\frac{\kappa_{path}}{\kappa_0}\right)^2+
\left(\frac{\ell_0}{\kappa_0}\frac{d\kappa_{path}}{ds}\right)^2\right]ds.
\]

其中 `kappa_0=1/r_min_ack`、`ell_0=r_min_ack`。它同时评价曲率大小和变化，适用于平移路径而非仅模式标签。

移动中的几何不连续或理想尖角不得因为各直线段曲率为零而得到平滑 PASS。正速度下的切线跳变/控制跳变须按动态约束拒绝，或显式优化成满足车辆模型的有限过渡。停车后重配置可以接受，但其调整事件和时间必须计入。

停车分隔的曲率不连续不伪装成有限曲率导数；分段记录曲率积分、边界跳变量及重配置事件。不得通过插入停车将转向动作从评价中消除。

### 6.2 O 稳定控制段与事件

- O 控制段内部 `phi` 恒定；需要变化时必须显式表示。
- 相邻 O 控制状态的实际改变计为调整事件，即使模式标签相同。
- 角差使用圆周规范，连续角变化须累计总变差，不能只比较首尾净角差。
- 任意有物理意义的小调整仍有变化量和执行时间成本。
- 初始事件数值去噪阈值为 `1e-4 rad`，它仅用于屏蔽求解舍入噪声；`1°` 可作“明显调整”报告门槛，不是免罚区。
- 去噪相对于上一个确认的稳定控制角进行，不能只比较邻近采样差；多个微调累计漂移达到阈值时必须被识别。总变差及执行时间仍按实际控制计算。
- 不得在 A/Spin 标签处简单清空所有控制历史。跨模式的真实轮角变化由重配置检查及执行时间计入，几何切线变化也要检查。
- 规范化合并只能合并实际等价控制段，不能合并不同方向来隐藏调整。

### 6.3 A 反复转向的诊断

除曲率与曲率变化积分外，报告有显著幅值的 A 曲率符号反复变化。使用固定滞回幅值 `0.10*kappa_0`，忽略零附近抖动；不是数原语或数离散控制节点。

在每个规范化连续 A 区间按弧长遍历：首次达到正/负幅值时确认符号且不计事件；进入零附近的滞回带时保留已确认符号；跨到相反幅值时计一次并更新符号。例如显著的左、右、左为两次符号反复。同模式内停车不重置历史；跨其他模式的区间边界另由真实控制重配置和时间评价。

该计数是偏好代理，不用作硬禁止：绕障碍可能确实需要 S 形路径。低幅值变化仍由曲率/变化积分和动态时间约束评价。

### 6.4 初始控制调整项

\[
J_{adjust}=N_{O,adjust}
+\frac{TV_O(\phi)}{\phi_0}
+0.25N_{A,reversal},\quad \phi_0=\pi/4.
\]

前两项抑制 O 反复调角，第三项对显著的 A 左右反复加小的行为偏好。执行时间已经计入真实重配置耗时，因此该项表达的是剩余行为复杂度偏好，不再给同一调整额外叠加任意大停车罚分。

轮级模型接入后，应统一检查四轮角总变差、转向速率和调整时间；替换代理指标时更新 profile，避免重复惩罚同一物理动作。

必报：平移曲率 RMS/最大值、曲率变化率 RMS/最大值、A 曲率总变差与显著反复数、O 调角数/总变差/最大角差、几何折角数、模式切换数、停车重配置数。无对应动作的 RMS 按定义为零；无法计算或违反连续性时为 UNKNOWN/INVALID，禁止伪填零。

## 7. 执行时间：包括加减速、旋转和重配置

### 7.1 初版执行策略

路径与时间可以分层求解，但完整候选排序必须包含时间规划反馈。初版对不能证明连续执行的控制/模式变化采用减速至零、有限时间重配置、再加速。持续行驶的连接必须满足同一车辆模型的连续状态、控制和能力约束。

\[
T_{exec}=T_{translation}+T_{spin}+T_{stationary\ reconfiguration}+T_{other\ holds}.
\]

各项按互不重叠的实际时间区间统计。若控制调整与行驶同时发生且已认证，只记录实际总耗时，不再重复相加。

### 7.2 重配置时间

启用轮级模型时，停车转向的一个必要时间界为：

\[
T_{steer}\ge\max_i\frac{|\Delta\delta_i|}{\dot\delta_{i,max}}.
\]

该式是速率约束的下界，不是所有情况下的精确时间；若角加速度、jerk 或机械模式切换延迟启用，还须加入相应限制。重配置阶段几何与速度也要检查。

同一模式内的 O 调角、A 停车打方向同样需要时间。不得只在模式标签变化时计算重配置。

### 7.3 时间规划检查

- 时间戳严格递增，速度和位置导数一致；Spin 平移速度为零。
- 标量速度平滑不能代替速度向量/角速度/控制连续性检查。
- 每段长度自动分配的 smoothstep 不构成加速度可行性证明。
- 路径尖角不能以正速度瞬间穿过；必须停车重配置或产生真实有限过渡。
- 不能通过任意放慢运动规避所有 cost：`T_exec` 明确参与质量比较，几何平滑指标使用空间测度。
- 缺少轮级模型时，可用声明的等效控制能力作研究 profile；必须标记 `kinematic_proxy`，不能标记实车验证。

必报：总执行时间及互斥分项、速度/加速/制动峰值、Spin 角运动峰值、转向速率峰值、限制余量、检查 profile 与结果。有限采样检查使用的覆盖界或分辨率必须记录。

## 8. Spin、辅助 O 与模式选择偏好

1. 正向 A/O/Spin 全部可参与搜索，不能采用“A/Spin 失败才开放 O”的规则。
2. Spin 保留给必要或综合表现更好的方案，不是硬禁用模式。
3. Spin 的整车扫掠、减速/起步、旋转和重配置时间全部计入；不额外使用未经解释的巨大禁转罚分。
4. A-S-A 与 A-O 必须在同起终点、同整车安全、同能力 profile 下比较，并允许切换位置和姿态一起优化。
5. 如 A-O 的净空、顺畅性和执行效率综合更好，应当获选；O 不能改变车体航向，不能要求在所有姿态任务中替代 Spin。
6. 稳定 O 明显降低 A 曲率、控制调整或执行时间时，应有机会获选。
7. 性能等价且运动等价的 A/O 直行，可将更简单的 A 作为末级平局偏好，不能把偏好变成禁止 O 的门槛。
8. 模式数量/切换数量是描述和末级偏好，少模式不自动优于稳定而有效的辅助模式。
9. 不要求固定 S-O-S、A-O-A 等模板；上游提前调航向由下游可达状态、净空及总代价决定。

## 9. 统一 Cost、归一化与候选排序

### 9.1 固定参考尺度

对一个冻结任务定义：

- `L0 = max(start_goal_xy_distance, vehicle.length)`；
- `T0 = max(start_goal_xy_distance/v_ref, abs(wrap(goal_yaw-start_yaw))/omega_ref, 1 s)`；
- `v_ref`、`omega_ref` 来自成本 profile 中固定的 `reference_speed_mps`、`reference_spin_omega_radps`，不随每次 `target_v` override 改变；当前值为 2.0 m/s 与 0.8 rad/s；
- `kappa0`、`ell0`、`phi0`、`d_pref` 按前文定义。

参考尺度不得来自候选自身长度或耗时，也不得因为候选池更新而变化。它们是无量纲化尺度，不是实际可行路径长度或准确最短时间的保证。

### 9.2 最终评分

仅对 FEASIBLE 候选计算完整评分：

\[
J_{total}=w_dJ_{clear}+w_gJ_{shape}+w_uJ_{adjust}
+w_t\frac{T_{exec}}{T_0}+w_l\frac{L}{L_0}
+w_r\frac{L_{reverse}}{L_0}+w_bN_{gear\ change}.
\]

`L` 为实际中心平移路程。Spin 由净空与执行时间评价，不给它虚构平移长度。

当前实现 profile：`quality_cost_v2_prototype_uncalibrated`。系数沿用原 v1 起始值，仍待成对偏好标定；版本号统一报告名和归一尺度，不代表权重已标定。

| 权重 | 起始值 | 作用 |
|---|---:|---|
| `w_d` | 4.0 | 对通行余量给较高偏好 |
| `w_g` | 1.0 | 抑制曲率与曲率变化 |
| `w_u` | 0.5 | 抑制 O 调整与明显 A 反复 |
| `w_t` | 1.0 | 控制实际执行耗时 |
| `w_l` | 0.25 | 小幅抑制绕行，与时间项有所区别 |
| `w_r` | 2.0 | 回退阶段抑制倒车距离；正向候选该项为零 |
| `w_b` | 1.5 | 抑制前后换向；跨 Spin 仍保留前一个平移档位 |

这些数是归一化后明确的工程起点，**尚未通过成对数据标定，不是最优权重结论**。目前用于 params.yaml 的独立 quality 后端，未用它替代 legacy 工程 cost。新增两项对纯正向候选均为零。正式标定版本必须通过第 11 节用例；若排序不符合约定，修改一个统一 profile 并重新评价全部校准与留出用例，不能逐图修权重。

### 9.3 排序与平局

1. INVALID 不进入最终候选池；GEOMETRY_VALID 不参与完整 FEASIBLE 排名。
2. 对所有方向可行候选按同一 `J_total` 比较；正向偏好仅通过显式倒车、换向和早段调整成本表达，不能用方向阶段硬优先覆盖其他质量项。
3. 分数差小于 `1e-4*max(1,abs(J1),abs(J2))` 时，依次比较：更低 O 调角数、更低 A 显著反复数、更少停车重配置、更少模式切换、更低终点误差。
4. 最后仅在运动等价的 A/O 选择中偏好 A。
5. 支持并报告 Pareto 候选，防止总分掩盖净空、时间等明显退化；不能以 mode word 直接宣布更优。
6. “好轨迹”是满足硬约束且符合成对行为偏好的相对评价，不设一个跨所有地图通用的 `J_total < 某数` 成功阈值。

### 9.4 内部代理与最终裁判

粗搜索可用长度、风险或时间下界/代理排序；连续优化可用平滑事件近似和距离代理。必须标明代理与最终指标的区别。

- 原始安全候选独立保存，精修失败不使其丢失。
- 优化后必须按实际轨迹重算精确分项。
- 模型目标下降不自动等于最终质量改善。
- 局部 NLP 失败/超时不证明整个模式序列不可行。
- 内部引导可暂时探索不可行轨迹，只有通过相应验收的候选才能输出合格结论。

## 10. 合理绕行与风险/效率权衡

用户接受合理的小幅绕行换取明显更好的净空与顺畅度，不追求最大净空或绝对最少模式。

标定时采用以下初始偏好带：增加路程不超过 `20%`、执行时间不超过 `15%`，如贴障指标或控制调整有显著改善，优先验证较顺畅方案应获选。显著改善在具体成对样本中声明；建议包括 `J_clear` 下降至少 `25%`、整车最小净空增加至少 `0.05*vehicle.width`，或去除至少一次有意义的反复控制事件。

这些百分比是**成对偏好标定起点**，不是运行时硬绕行上限。实际绕障碍、避窄口或满足正向/姿态条件可能需要更大路程；不能按直线距离加 20% 硬剪枝。其他质量维度明显恶化时，不能只凭上述一项改善判优。

更大绕行保留为 Pareto 候选，按完整 cost 和任务优先级评价。累计风险有饱和范围，时间和路程持续计费，阻止只为额外净空无限绕行。

## 11. 成对偏好与反作弊验收用例

每个用例必须提供相同任务、能力、地图和评价 profile；下面是通用测试条件，不是地图状态机。除明确考察某个代价项外，匹配其他质量项或记录其差异。

| ID | 对照或干预 | 必须得到的结果 |
|---|---|---|
| Q01 | 碰撞短路线与安全长路线 | 碰撞路线 INVALID，无有限分数使其获胜 |
| Q02 | 质量相当的正向路线与倒车路线 | 其他重要指标相当时，少倒车路线获偏好；净空/曲率收益足够时允许倒车 |
| Q03 | 极端窄道上的全程倒车 | 只要满足方向符号、车身扫掠、动态和目标检查，保持可行并参与统一排序 |
| Q04 | 频繁前后揉库与单向/切模式路线 | 对无必要换向明显惩罚；若反向对安全可行性或轨迹质量必要，仍可选，换向和倒车指标需逐项报告 |
| Q05 | 较贴边短路线与偏好带内明显更宽裕路线 | 无其他显著退化时，宽裕路线获选 |
| Q06 | 只有满足安全缓冲的窄通道可行 | 不因低于 d_pref 拒绝；报告低余量及风险分 |
| Q07 | 两条路线均达到 d_pref，后者只为更多净空明显绕远 | 后者无额外净空奖励，时间/路程使其落后 |
| Q08 | 自然 A 转弯与净空区不必要多角度 O 拼接 | 在其他项匹配时自然 A 获选 |
| Q09 | A 大曲率反复与安全稳定 O，其他项匹配 | 稳定 O 可获选，不因 O 标签被排除 |
| Q10 | 稳定 O 与有实际变化的多个 O 方向段 | 匹配其他项时稳定 O 获选 |
| Q11 | A-S-A 与净空/顺畅度更好、耗时处于偏好带内的 A-O | A-O 获选；不套用固定替换规则 |
| Q12 | 需要改变车体航向且其他方案不可行 | 保留可行 Spin 方案，不为了禁 Spin 接受错误终点 |
| Q13 | 同样可行的末端反复调整与上游提前调整 | 控制/净空显著改善且效率处于偏好带内时，上游方案获选 |
| Q14 | 同一精确路径/控制/时间，采样点数翻倍 | 所有积分项基本不变；相对误差 <= 1e-3，不改变排名 |
| Q15 | 将相同控制段拆成多个等价段 | 规范化后事件、时间和 cost 不变 |
| Q16 | O 分段内每条直线曲率为零，但边界有折角 | 仍检测折角/调角及动态过渡，不能报零调整平滑路线 |
| Q17 | 插入短 A/Spin 标签隐藏 O 调整或跨模式轮角变化 | 仍记录真实控制变化/重配置；标签本身不能抹除成本 |
| Q18 | 将短 O 段瞬间提速，或正速度瞬间换方向 | 动态 INVALID；有限加减速候选才可进入完整排名 |
| Q19 | 未提供速度/加速度/转向能力或验证 | 动态 UNCHECKED，完整 J_total 为 null，不能称 FEASIBLE |
| Q20 | 相同几何通过任意慢速降低动态变化 | 几何分项不变，执行时间增加；不能无成本获益 |
| Q21 | 沿 O 路线多次微调，首尾 phi 相同 | TV/实际事件和调整时间不为零 |
| Q22 | 已有安全原始候选，精修失败或分数更差 | 原始候选仍保留，预算结束可输出 |
| Q23 | Spin/停车点大量重复采样 | 不稀释曲率 RMS，不重复计算几何长度/净空积分 |
| Q24 | 相同路线使用不同随机种子/求解器或初解来源 | 精确轨迹相同则评价相同；求解时延另报 |

Q14 的误差界具体取 `abs(J_fine-J_coarse) <= 1e-3*max(1,abs(J_fine))`，分别适用于每个积分分项；事件数应在规范化后相同。检查分辨率不足时加密验证，不能靠放宽误差门槛通过。成对排序必须留出数值误差裕量。

## 12. 权重标定与版本冻结

1. 构造通用成对轨迹库，覆盖开阔区、直角弯、交错障碍、斜窄通道、泊车入口及必要 Spin；同时包含不同尺寸/姿态，不根据某一地图结果选权重。
2. 先完成硬约束、指标和时间规划的定义一致性，禁止用权重弥补错误指标。
3. 使用 `quality_cost_v1_initial` 重算分项，检查第 11 节适用的严格偏好对。
4. 有冲突时定位 cost 项、归一化或候选真实物理差异，再统一调整权重；不存在一组权重满足重要偏好时修改模型，而不是隐藏冲突。
5. 可用成对约束 `w dot (f_bad-f_good) >= epsilon` 辅助标定；约束裕量在归一化尺度下声明，保留所有冲突样本。
6. 校准库与留出库分离，冻结正式 profile 后再做 N01–N06 与论文地图验证。
7. 同时保存 Pareto 指标和成功率，不能只报告总分平均下降。
8. 权重/能力/终点/缓冲改变后建立新版本；新旧总分不得直接相减宣称收益。

## 13. 求解效率合同

### 13.1 计时

用同一单调时钟从规划请求被接受开始记录：地图/状态已就绪条件、首次几何合格时间、首次完整 FEASIBLE 时间、最后一次质量改进时间、最终发布/返回时间。粗搜、NLP、模式搜索、时间规划、最终验证分项累计。

报告 `t_first_geometry`、`t_first_feasible`、`t_total`；动态未检查时 `t_first_feasible=null`。当前 optimizer 的局部 `time=` 不能单独替代端到端时延。

### 13.2 预算与持续改进

- 请求开始冻结总 wall-time 预算，所有子问题共用预算并预留最终验收时间。
- 首先寻找合格结果，再在剩余预算中改进；原始合格结果始终保留。
- 单次 NLP 有独立上限，避免一个不可解分支耗尽全部预算。
- 缓存几何/模式连接和可复用解，去除实际等价求解。
- 优先精修有竞争力且结构不同的方案；粗 cost 是引导，未证明的估计不得当成严格下界剪掉候选。
- 正式安全检查不因预算不足而跳过；超时无完整合格结果则报告未找到。

### 13.3 性能报告

同预算、同硬件、同任务/profile 下，至少报告：成功率，首解和总时延 P50/P95，最终质量分项，质量随时间变化，重复运行波动，超时率及超时后有无合格 incumbent。

“更快”不得单独掩盖明显质量退化。若用更短预算换取略差质量，明确给出折衷；不要把 timeout 当作不可行证明。

## 14. 评价输出与归因

每次实验输出可复现 JSON，至少包含：

| 字段组 | 必需内容 |
|---|---|
| 来源 | task_id、candidate_id、parent_id、初解来源、改进操作、代码/地图哈希 |
| 合同 | spec_version、cost_profile、能力 profile、缓冲/终点/数值容差、冻结参考尺度 |
| 合格性 | geometry/forward/terminal/dynamics/model/independent_sweep 状态及拒绝理由 |
| cost | J_clear/J_shape/J_adjust/T_exec/L 的原始量、归一化项、权重贡献、J_total |
| 行为 | 模式词、模式/控制段边界、真实 O 调角、A 反复、Spin、停车和重配置 |
| 质量 | 整车净空、曲率/变化、控制变化、端点误差、动态峰值和余量 |
| 性能 | 首几何解/首完整解/总时延、子阶段时间、预算/超时、质量时间序列 |
| 验证 | 检查器版本、采样/覆盖策略、约束残差类别、重复次数、清理信息 |

未知值存 `null` 与理由，不填零。严格 JSON 不保存 NaN/Infinity；INVALID/UNCHECKED 的完整 `J_total=null`。

改善分别归因于：拓扑/模式结构、切换边界/姿态、固定模式几何、时间规划、候选保留、求解调度。Bonmin 返回进入它之前就已形成的更好模式初值，不能记作 Bonmin 新发现的离散收益。

## 15. 当前工程差距与重构接口

| 当前能力/差距 | 按本规范的后续要求 |
|---|---|
| 当前 sequence_cost 以等效距离、模式与控制代理为主 | 新评价器明确整车净空、曲率变化、O 调整、实际执行时间 |
| 当前有中心净空下界 | 不能直接作为最终整车最小净空指标 |
| 当前 smoothstep 只按长度和演示速率分配时间 | 增加能力约束时间规划及边界重配置 |
| 当前 O 同模式组可在非零速度下改变方向 | 显式控制段与有限过渡/停车重配置 |
| 模式选择与 seed 的 knot/锚点结构绑定 | 模式段与几何节点分离，自由边界姿态及全路径优化 |
| 部分精修失败会丢掉安全模式候选 | 每条原始安全候选独立保存 |
| 历史规范曾将反向限制为回退且拒绝全程倒车 | 统一双向候选与成本；反向偏好软化，全程倒车在极端任务中可行 |
| 当前 MINLP 与局部优化收益容易混淆 | 统一指标、独立合格性与逐候选归因 |

建议重构为三个清晰接口：

1. **候选表示/模式搜索：** 输出区域、模式段、自由边界及初始几何，允许结构增删和连接改变。
2. **连续与时间子问题：** 固定一次模式方案，联合优化全路径及边界，并产生满足能力约束的时间轨迹；结果反馈模式搜索。
3. **独立评价器：** 按本合同检查、评分、规范化和保存候选；对所有初解来源保持一致。

本规范不表示连续走廊 NLP、多拓扑模式搜索或 MINLP 已完成。R06 方案按本合同推进这些重构；当前权重仍是未标定原型。

## 16. 方法依据与适用边界

- [Chang 2026，空间联合模式与路径规划](../papers/13_Chang_Spatio_Temporal_Decoupling_2026.pdf)：借鉴空间层同时决策模式、位姿和控制；具体车辆模型、求解器及约束需独立核对。
- [INSAT](https://arxiv.org/abs/2210.08627)：借鉴离散搜索与连续优化互相反馈、复用邻域解；非凸子问题失败不作为全局不可行证明。
- [TOPP-RA](https://arxiv.org/abs/1707.07239)：借鉴固定路径的速度/加速度可达性规划；本项目还需处理 Spin、停车重配置和声明的转向约束，不能直接套用论文保证。

本文的偏好、数值起点和评价合同属于本项目设计，不声称来自论文的已验证最优参数。
