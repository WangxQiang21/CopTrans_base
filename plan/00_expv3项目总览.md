## 目录

最快看 Demo（在有图形桌面的终端执行）：

```bash
cd /home/wq/whut_thesis
./expv3/run_demo.sh
```

脚本会构建 overlay、启动 ROS/RViz，并自动规划 S09 默认目标。手动测试论文地图时先列出地图，再按名称启动；此模式默认关闭自动目标，起终点在 RViz 设置：

```bash
./expv3/run_demo.sh --list-maps
./expv3/run_demo.sh --map P12_env1
./expv3/run_demo.sh --map P12_env1 --map-scale 0.9
./expv3/run_demo.sh --map P12_env2 target_v:=2.0
# 也可传包含 map.yaml 的目录路径
./expv3/run_demo.sh --map /path/to/map_directory
```

P12_env1 默认以地图中心为基准缩小到 0.5 倍，P12_env2 默认缩小到 0.7 倍；`--map-scale` 可覆盖比例。缩放只改运行时地图分辨率和原点，不重采样栅格，起终点需在新坐标系中重新设置。

首次启动可等待几秒；详细操作和无图形环境选项见 [Demo 使用说明](../catkin_ws/README.md)。

## 当前结论

最适合 expv3 主线的组合是：

```text
ROS/RViz 设置起点和目标
        ↓
车辆中心模型 + 多条二维拓扑初值
        ↓
安全走廊内 A/O/S 模式变量与连续轨迹联合优化
        ↓
独立 OBB 连续扫掠 + 终点验收
        ↓
时间化为逐点 (t, [x,y,v,θ])，复验并在 RViz 显示
```

小车前后严格对称，车长 `0.738 m`、轴距 `0.494 m`，前后悬均为 `0.122 m`；车辆中心就是前、后轴中心的中点。前后轴反向转向，按双阿克曼模型规划。规划、ROS 起终点和输出统一使用车辆中心，输出带时间戳的 `[x,y,v,θ]`，其中 `v` 为车辆中心平动速度大小，Spin 段 `v=0`。推荐目标架构是在拓扑走廊内联合决定 A/O/S 模式与车辆中心轨迹，核心分析见第 05 文档。当前稀疏路线图已能在同一离散图中比较 O 平移、Spin 和 Reeds–Shepp A 连接弧；状态携带上一模式、控制分箱及档位，代价包含换模、倒车、控制变化、曲率和斜移量。它仍是有界候选图而非全局联合最优：A 弧只连相邻数个航点，且只在低/中/高净空代表路线运行；其他二维路线仍贡献 O/Spin 候选。当前 `w_oblique_use=0.55`、`w_oblique_cruise=0.45`、`w_oblique_tv=0.35` 是工程权重，需跨场景消融，不代表已标定。`joint_refine` 完整整数—连续 MINLP 仍不稳定，因此默认关闭。

## 当前可运行主链与近期验证

当前 Demo 尚未实现上方推荐的 corridor 内完整整数—连续联合优化，实际可运行主链是一个 anytime 分层粗搜：

```text
地图安全净空场
  → 多个净空权重的 8 邻接位置 A* 拓扑候选
  → 生成多个 2D 拓扑；低/中/高净空路线运行有限 A/O/Spin 航点图
  → O 平移 / Spin / Reeds–Shepp A 弧按同一代价并经过 swept-OBB 验证
  → 候选作 incumbent 后限额运行 A/O/S Hybrid A* 继续竞争改进
  → 固定事件序列连续优化与安全时间化；失败时回退到经独立 SAT 复核的粗解
  → 安全时间化和 ROS/RViz 发布
```

有 incumbent 时 Hybrid A* 默认设为 1.5 千扩展上限；没有可行 incumbent 时仍允许最多 18 万扩展。因此“1.5 千”是有可行解时的改进预算，不是无解时的全局超时保证。C++ 搜索与 Python `sequence_cost` 统一使用换模、倒车/换向、Ackermann 转角总变差与曲率、斜移角总变差、距离加权斜移量、Spin 等项。行驶长度是基础等效距离，Spin 项取 `v_demo/omega_demo=1 m/rad`，因此与当前演示速度相同时二者时间比例一致；换模及转向平滑仍是距离等效的工程正则项，尚不是实车标定时间。稀疏混合图状态携带模式、控制分箱和档位，量化导致近似；还原后按精确动作序列 cost 复核。基础 footprint guard 为 5 mm，O 边采样步长默认 10 mm，A 图边默认 40 mm，各样本额外膨胀半采样位移覆盖样本间扫掠；Hybrid A* 和 Python 后端/时间化分别验证，最终仍独立做 OBB-SAT。时间化显式保留每个控制原语边界；安全时间化失败时仅在原始粗解再次通过后端扫掠和终点检查后回退。

2026-10-01 后续修正了优化器内层与粗搜评分不一致的问题：固定序列 NLP 现在包含相同的距离、Spin、倒车、换模、换向、Ackermann 曲率/转角变化及斜移代价，并以平滑绝对值改善 IPOPT 收敛；每个粗动作最多 1m/30° 一个优化节点，迭代上限 100。达到上限的返回值仅作为候选，仍须通过重放、终点容差、共同代价不变差和整车 sweep。

随后新增锚点 DAG 模式候选：在安全粗路径相邻最多 3 个锚点之间重新拟合 A/O/Spin 原语并做 swept SAT，允许合并粗动作、改变中间几何和模式切换锚点；当前固定序列解保留为 incumbent，最多对一个有竞争力的锚点提议做 NLP 精修。缓存每条锚点边的模式拟合与 SAT 后，19 项单测通过；6 个有效 S09 预设和两个额外揉库目标均通过独立终端轨迹扫掠，障碍内目标被正确拒绝，共 8 条有效轨迹、23,156 个独立 OBB/SAT 扫掠样本。模式包含 A/O、O/Spin、A/O/Spin；两个真实例子由锚点/几何重规划获得改进：揉库目标由固定序列 16.445 降至 16.213（O/Spin/O），顶部斜车位由 14.944 降至 14.673（A/O/Spin），均通过独立扫掠。另一个揉库目标锚点候选 16.038 高于固定序列 15.916，故保留固定解。完整当前回归的粗搜约 0.13–1.39s、后端约 0.43–2.82s。

有安全 incumbent 后的 Hybrid A* 改进预算从 2500 消融到 500/1500：500 在多个目标上复现同解，但顶部斜车位退化为代价 15.069 的粗解回退；1500 找到 14.673 的安全优化解，因此默认采用 1500。昂贵的混合 A/O/Spin 图则从净空权重 `0/1.5/3` 减为 `0/1.5`，四条路线仍参与便宜的 O/Spin DP；完整测试的最终代价不变。最慢远端混合图耗时约 `1.13→0.78s`、总粗搜 `1.71→1.39s`；顶部斜位混合图 `0.80→0.56s`、总粗搜 `1.22→0.98s`。预算只限制已有解后的改进，不改变首次找解上限。全局模式—几何 MINLP 的共同代价已修正，但 S09 难例仍触发 Bonmin `LIMIT_EXCEEDED`，耗时约 8s，继续默认关闭。

针对最新 RViz 反馈，TimedPoint 增加逐点模式字段，HUD 显示当前模式，ego 车体增加朝向箭头；粗解与优化解有独立 Path 和模式色带，A/O/Spin 分别用青/橙/紫色。斜移连续优化使用小权重控制调整事件正则，与粗层候选代价分开，避免整体抬高 O 模式代价。S09 默认目标 O 角度调整由 4 次降到 2 次（≤5°的小调整由 2 次降到 1 次），共同评分 12.853→12.503；窄位揉库目标 `(3.387,4.950,1.567)` 的独立扫掠通过。S09 可视化与轨迹 smoke 验证通过，具体当前时延见下一段；这些仍是小规模 S09 结果，不代表多场景时延保证。

继续 profiling 后，将整车 SAT 从逐格 Python 循环改为局部占据栅格切片上的 NumPy 向量计算，四轴分离判据不变；400 个随机位姿与标量 SAT 逐项一致。默认目标后端从约 `1.95s` 降至 `0.87s`，窄位揉库目标从约 `1.69s` 降至 `0.76s`，两者 swept 复验均通过；默认线搜索扫掠约 `0.33→0.026s`、锚点边检验约 `0.43→0.032s`。当前默认目标总 ROS 规划约 `0.48+0.87s`。进一步加大 NLP knot 间距或把 IPOPT 迭代上限由 100 降到 80，均造成揉库目标代价/角度调整恶化，因此撤回，保留原质量设置；NLP 100 次迭代约 0.62s，仍是后续优化热点。现在单测为 20 项；另跑过默认目标、Spin、纯斜移及窄位揉库 ROS smoke，独立 SAT 安全检查通过。

另外试过放宽 IPOPT acceptable tolerance，但求解依然达到 100 次迭代上限，默认目标总耗时/评分没有收益，已恢复原求解容差。当前性能改进仅来自保持精确判据的 SAT 向量化；下一轮重点应放在缩短 IPOPT 迭代而不牺牲窄位模式/几何质量。

IPOPT 上限已参数化（`optimization/max_iter`）。将默认 100 降到 60 的困难目标对照仍通过 sweep，但揉库解 cost 从 16.213 升至 16.372；顶部斜位从 14.673 升至 14.896，且该例的总耗时没有改善。因此默认仍为 100，60 作为可调速度/质量折衷，不宣称更优。

2026-10-01 针对最新 RViz/轨迹意见做了迭代：A 与低角度 O 的公平比较中新增 `w_oblique_cruise=0.45·exp(-φ²/(2·25°²))` 每米项，并把大角度斜移量权重从 `0.35` 提到 `0.55`；这不是禁止斜移，仍由同一总代价和碰撞约束决策。速度参数是时间化/可视化参数，默认 `v_demo=ω_demo=2.0`，Smoothstep 平移组目标平均速度约 `1.33m/s`（峰值 `2m/s`），并在 ROS smoke 中对平均值设了 `>1m/s` 门槛。查到 MarkerArray ADD 线条 marker 未初始化姿态四元数（默认全零）会触发 RViz 告警；最终/粗解色带及走廊包络现在显式使用单位四元数，DELETEALL 使用 `frame_id=map`，C++ Endpoints 清除标记也补上 frame/stamp。Smoke 会检查每个 ADD marker 的 frame、单位四元数、正尺度和有效点数。

新增基于“末端模式/档位切换复杂度”触发的有界 terminal-local anytime A/O/Spin 重搜索，并在终点轴线前采样 approach pose；它只生成几何候选，最终连接和序列仍由共同代价及独立扫掠验收决定，不写死模式序列。S09 #2 ROS smoke：轨迹 6.45s、平移平均 1.34m/s、最终 A/O/Spin，优化器约 0.71–0.98s，时间化 sweep 通过。S09 #7 斜车位：最终 A/O/Spin，优化器约 0.70s，仍保留 2.39m 的斜移，说明成本没有禁掉确有用途的 O。S09 #5（MID_B 开口向南）：最终为 O/Spin、无倒车，平移平均 1.33m/s，时间化 sweep 通过。无倒车是搜索选出的轨迹特征，不是目标失败；该结果仍需在统一 Ackermann 基线和多场景指标下评估末端误差、连续性、净空与代价。末端局部图当前只是有限姿态候选的启发式，不代表一般的终端联合优化。23 项 Python 单测和 catkin C++ 编译通过；ROS smoke 覆盖 #2/#5/#7。以上是 S09 单图验证，不是多场景性能保证。

仍未达成最终目标：稀疏图已含 A/O/Spin，但 A 弧只由有限长度 Reeds–Shepp 连接器和离散航向近似覆盖，连续姿态和其他同伦类仍可能漏掉；验证仍集中在 S09，最慢有效粗搜约 1.39 秒、后端约 2.82 秒。新增状态遥测报告曲率总变差、明显曲率变化数、斜移角总变差和倒车距离；不能把离散原语数误当成打方向次数。Spin 平移时间比例按演示速度标度，但换模、转向平滑和斜移惩罚仍是工程代理项；尚未完成多场景 Pareto、权重扫描及其他车库图统计，因此不能声称该版本已最优或最终完成。
