## 1. 最新需求合同

### 1.1 停车与连续运动

| 事件 | 必须满足的行为 |
|---|---|
| A 模式同方向内改变曲率/轮角 | 连续转向，连续速度；允许根据能力约束减速，不能因原语、采样点或 NLP 节点而停车 |
| O 模式同方向内改变斜移角 | 角度与速度连续，满足转向速率及平移加速度约束；由成本减少无效调角，不强制停车 |
| A/O/Spin 之间切模式 | 减速到零、静止完成模式及轮角重配置、再起步 |
| A/O 内前进与倒车换向 | 有符号速度连续经过零；不增加静止等待，不把它记为模式切换 |
| 连续 Spin 节点 | 中心平移速度为零，角速度连续；不能每个旋转原语重新启停 |
| 任务起终点 | 速度为零；保持用户指定的车体航向与位置 |

“不停车”不等于强制保持恒定高速。若必须减速满足轮角速率、横向加速度等约束，就减速。若某几何候选只有插入同模式静止等待才能可行，则该候选不满足本轮行为合同，应修复连续几何或重新规划。

瞬时曲率跳变不能直接通过删掉等待时间修复；几何控制必须先变连续。Spin 中有角运动的时间不能误算成“额外静止等待”。

### 1.2 行驶方向

- 合理倒车作为正常决策，与正向候选在同一个候选池竞争。
- 不再使用“先有正向解就永不考虑倒车”的硬排序。
- 不再以“全程倒车”标签直接拒绝安全、精确且更合理的连续倒车路线。图 19 的直走廊倒车就是必须覆盖的行为。
- 保留轻微的前进偏好用于基本等价候选；重点惩罚实际的前后换向、反复调整及其停车/再加速时间。
- 用有符号的平移速度和方向变量表示倒车，不翻转用户目标航向或伪造正速度。
- O 的规范斜移角范围仍为 `[-pi/2, pi/2]`。纯侧移的符号需结合控制与速度核对，不能只靠车体纵向投影判断。

### 1.3 终点

- 起终点使用车辆中心坐标，目标箭头的根部对应目标中心。
- 连续优化固定真实目标的 `x/y/theta`，不以粗解末端代替真实目标。
- 粗搜索候选容差与最终发布容差分离。
- 本轮最终独立验收初始标准：位置误差不大于 **0.02 m**，最短航向角误差不大于 **1°**；连续优化目标仍是目标等式，而非故意用满这两个容差。
- 最终目标姿态碰撞时报告目标不可行；不能静默移动目标。
- 窄处无法修正航向时，提前在宽处调整并改变后续几何；不能只修改最终姿态数值。

### 1.4 模式与质量

- A、稳定 O、必要 Spin 及行驶方向共同优化，粗解仅是初值。
- 平顺 A 能完成任务时不为使用 O 而额外切换。
- 稳定 O 能明显缩短路线、减少大曲率或无效转向时允许获选；不能设置 A 优先、O 兜底的模式族门槛。
- 减少连续 O 调角和通过极短其他模式片段掩盖的 O 反复调角。
- 安全、运动学、动态能力和精确终点属于合格条件；路程、时间、净空和控制复杂度属于统一偏好。
- 不按 P11/P12/N03/N05 等地图名称写规划分支、状态机、固定模式序列或专属权重。

## 4. 目标数据流和接口

```text
原始任务：地图、真实起终点、能力、方向策略、统一预算

  → 模式结构与方向提议
```

### 4.1 必须区分四种边界

1. 几何积分/采样节点：用于表示与检查，无停车语义。
2. 同模式控制节点：曲率或斜移角的连续控制节点，无停车语义。
3. 方向换向点：有符号速度过零，不插入静止等待。
4. 模式切换点：中心速度为零，允许有限静止重配置。

数据结构建议：

- `MotionBlock`：模式、方向、控制节点、区间长度、起终姿态、连续插值类型。
- `ControlKnot`：弧长位置、控制值及必要的一阶导数；不存 `must_stop` 默认 true。
- `TransitionEvent`：旧/新模式、换向标记、停车原因、轮角端值、重配置时间。
- `ContinuousPlan`：全部几何块、过渡事件、真正的起终目标、能力 profile。
- `TimedPlan`：连续时间合同、发布样本、各阶段耗时、误差界和检查结果。

初期可保持 ROS `PlanSeed.primitives` 作为粗初值接口，`TimedTrajectory` 作为执行/显示接口。新连续控制和时间合同放在伴随 JSON 中，版本化为例如 `continuous_motion_v2`。旧 `exact_primitive_quintic_v1` 原件仍可读取，但不能冒充新连续转向合同。

`ModePathMaster` 获选候选必须保存实际的连续几何，不可继续只保存不能完整描述轨迹的恒定 `Action[]`。粗原语、连续几何、样本必须能分别核对，不能把它们当成同一种表示。

## 6. WP1：连续控制几何，先解决“节点就是停车点”

### 6.1 实施路径

1. 将连续同模式动作识别为几何块；方向变化可以分块，但不是模式重配置事件。
2. A 块以弧长上的连续曲率表示，至少保证曲率 C1；O 块以连续斜移角表示，稳定 O 可以只有一个常值控制。
3. 推荐使用分段三次 Hermite 或其他可显式求导的控制插值。节点控制值、必要导数、区间长度及中间状态由 NLP 调整；不要把原粗动作边界姿态全部锁死。
4. 增加连续控制运动积分。几何重放和 NLP 采用一致方程，数值积分误差要报告并自适应减小。
5. 不把线性插值的显示位姿当成连续车辆运动学模型。平滑控制改变后路径通常也改变，必须重新优化位置/航向及扫掠检查。
6. 不通过近似合并两个不同曲率的恒定圆弧假装连续转向；等价合并只能用于真正等价的控制。

### 6.2 方程与符号约定

令 `ell` 为非负累计平移路程，`epsilon` 为方向，`u=dell/dt>=0`，发布有符号速度 `v=epsilon*u`。

A：

```text
dx/dell = epsilon*cos(theta)
dy/dell = epsilon*sin(theta)
dtheta/dell = epsilon*kappa(ell)
```

O：

```text
dx/dell = epsilon*cos(theta + phi(ell))
dy/dell = epsilon*sin(theta + phi(ell))
dtheta/dell = 0
```

Spin 保持 x/y，不用平移弧长除以零，使用独立的连续角运动表示。

Hermite 的导数必须是物理弧长导数；若使用归一化区间变量，必须正确乘除区间长度。曲率范围、斜移角范围和峰值验证不能只检查节点值，插值区间内部也可能过冲。

theta 在内部积分与时间检查中连续展开，终点角差使用 2π 周期的最短差；跨 ±π 的正常转弯不能产生伪造的角速度峰值，也不能把 π 的航向反转当成同一目标。

四轮角和速比沿用车辆中心模型，A 轮位置为 `(xi,yi)`：

```text
delta_i = atan2(kappa*xi, 1-kappa*yi)
wheel_speed_magnitude_i = u*sqrt((1-kappa*yi)^2 + (kappa*xi)^2)
```

O 的四轮角等于 phi，平移轮速幅值等于 u。Spin 保留各轮规范化角与对应的有符号滚动方向，不把所有轮的速比正号当成实车轮速指令。

### 6.3 验收

- 常值 A/O 与旧 `advance()` 回放在数值误差范围内一致。
- A 直线到弯道、左右连续弯的曲率/轮角连续，没有曲率台阶。
- O 有限调角时车体 theta 恒定，位置路径按新方程积分。
- 正向与反向的几何、yaw 增量符号正确。
- 控制插值内峰值在界内；起终点满足新严格目标，不用显示层掩盖积分漂移。
- 几何节点细分不改变模式/控制事件和路线质量。

必要时可保留恒定原语为初值和历史分析格式；新后端实际候选必须先转成合格连续几何才进入完整评分。

## 7. WP2：模式块内连续速度与转向，切模式才静止重配置

### 7.1 删除的错误依赖

- 不再每个 `Action` 独立使用零速到零速 quintic。
- 不再因同模式 `wheel_angles` 不同而生成静止 reconfiguration。
- 时间规划不能把 NLP 网格密度转化为启停次数。

### 7.2 时间规划方法

在一个同模式同方向连续几何块上，共同求解弧长进度 `ell(t)` 或速度节点。可以先用速度上界包络及前后向传播建立加速度可行初值，再用小型时间 NLP/平滑速度表示满足 jerk、转向和角运动约束。

速度节点的平方速度方法可用于可行初值，但仅靠前后向加速度传播不够证明 jerk/转向加速度合格；最终必须有可微时间合同和独立检查。

起终点、模式切换点设 u=0；内部控制节点不设 u=0。换向点 signed v 连续过零，不加入 dwell；轮角也须连续，必要的轮角变化在前后移动区间完成。

模式切换处理仍包括：停稳后保持同一中心姿态，有限时间转轮角与模式设置，然后下一模式起步。机械设置延时与转轮过程并行还是顺序必须在能力 profile 中声明；本轮可先沿用顺序模型，但要避免重复计时。

### 7.3 必须验证的动态关系

在 A 同方向区间，以下式子中的 a、j 是非负弧长进度速度 u 的一阶、二阶时间导数，不是始终非负的数：

```text
omega = epsilon*kappa*u
alpha = epsilon*(kappa*a + kappa_prime*u^2)
angular_jerk = epsilon*(kappa*j + 3*kappa_prime*u*a + kappa_second*u^3)
delta_dot_i = (d delta_i/dell)*u
delta_ddot_i = (d2 delta_i/dell2)*u^2 + (d delta_i/dell)*a
lateral_acceleration_magnitude = u^2*abs(kappa)
```

O 连续调角时：

```text
theta_dot = 0
phi_dot = phi_prime*u
phi_ddot = phi_second*u^2 + phi_prime*a
path_normal_acceleration_magnitude = u^2*abs(phi_prime)
```

因此 O 即使车体不转，也不能忽略改变速度向量方向产生的平移加速度。

检查：平移速度、路径进度加速度/jerk、路径法向加速度、body 角速度/角加速度/角 jerk、轮角/轮角速率/轮角加速度、轮速。不要只用旧常曲率公式 `alpha=kappa*a` 检查变曲率 A。

现有 `a_max/jerk_max` 描述路径进度。若增加笛卡尔合加速度或 wheel acceleration 约束，新增清楚的参数与独立检查，不混用现有字段含义。不能声称已经验证任意向量 jerk。

### 7.4 独立检查与报告

改造 `quality._check_timing()`：支持并重放连续时间合同，检查几何/速度/轮角和 phase 连贯性，不再要求每个 phase 对应一个常值 Action。

每条发布轨迹保存：

- `interpolation_version`、连续块和控制节点、各阶段起止时间；
- `mode_switch_count`、`direction_switch_count`、`control_knot_count`；
- `mode_switch_hold_seconds`、`same_mode_hold_seconds`、`gear_change_hold_seconds`；
- `internal_same_mode_stop_count` 与检测阈值/停速原因；
- 速度、加速度、轮角及角运动峰值，分解析/模型检查与发布采样独立估计；
- 积分/插值误差及动态验收状态。

本轮行为目标：same_mode_hold_seconds=0，gear_change_hold_seconds=0。普通开放空间的同向 A/O 控制边界处速度应为正。换向的单个零速点、任务端点、Spin 的零中心速度与模式切换停车要单独分类。

停车检测至少声明速度阈值与持续时长，例如 `|v|<0.01 m/s` 持续 0.1 s，再结合位置/角运动、事件类型分类。开放空间非换向行为测试可要求内部控制边界 `|v|>0.05 m/s`；这是该行为测试的门槛，不是所有窄通道的最低速度硬约束。不能把停车替换为极小 epsilon 速度爬行来绕过统计，仍需检查实际执行时间和连续控制能力。

### 7.5 必测行为

| 用例 | 通过条件 |
|---|---|
| 开放空间直线→弯道→直线，全 A | 内部节点无停车等待，控制边界速度不归零，轮角变化有限 |
| 连续左右弯，全 A | 轮角穿过零连续，无因转向符号变化而停车 |
| 弯道拆成不同数量几何节点 | 停车次数不增加，时间与 cost 在声明的数值误差内一致 |
| 连续 O 有限调角 | theta 恒定，phi 和速度连续，无静止调角，动态约束通过 |
| A→O→A | 仅两个模式切换产生重配置等待，无额外节点停车 |
| A→Spin→O | 两个模式切换停车；Spin 期间中心静止、角运动合法 |
| 同 A 前进→倒车 | signed v 过零、无额外 dwell，轮角与速度合同连续 |
| 多个同向 Spin 原语 | 合成连续角速度过程，不逐原语启停 |
| 很短的移动段 | 仍有有限加减速，不能瞬间达到巡航速度 |
| 伪造速度/轮角/时间 | 独立检查明确失败，不能仅看 solver success |

原 `test_oblique_angle_change_stops_and_reconfigures_even_without_mode_change` 应替换为不强制停的动态行为测试。保留短段加减速与错误时间合同的测试意图。

交付：WP1/WP2 连续表示、时间规划、独立验收和上述行为证据。未达到这些条件前，不声称新后端已经解决弯道停车。

## 8. WP3：方向与精确终点合同贯通

### 8.1 配置与接口

建议新增统一 `planning.direction_policy`，值为 `bidirectional` 或 `forward_only`。新后端的正式策略为 bidirectional，forward_only 用于消融。

迁移旧 `allow_reverse_fallback`：从主参数中撤下旧默认布尔字段，保留显式旧 CLI 参数的兼容入口。若用户显式传旧 true/false，可映射到 bidirectional/forward_only，并打印迁移说明；新旧参数同时指定且冲突时报告配置错误。不要把字符串 `false` 当成真值。

planner 与 optimizer 必须接收相同的有效策略。legacy 的历史方向策略可保留，但启动报告明确是历史对照，不用它验证新双向合同。

### 8.2 方向改造清单

1. C++ 正常搜索与终端连接生成 A+/A−、O+/O− 候选，不先消耗全部正向预算再开放反向。

## 9. WP4：模式候选与路径联合优化

目的：让图 9/10/16 的更自然结构确实进入竞争，而不是只对粗解的模式做连续微调。

实施：

1. 正常候选池使用模式与方向的联合标签，不把同一 A/O 模式词中的不同方向序列合成一个候选签名。
2. 从多个位置拓扑、航向初值和模式结构构建有界初值银行。直连、稳定 O、A 圆弧/连续曲率、可行 Spin、正/反方向连接都可作为通用几何提议。
3. 使用区域净空和车体可行航向信息提出上游调整位置；候选包括删除、替换、增加模式段和移动边界。不能只允许在完全相同的粗姿态之间拟合一个 O。
4. 将上游重规划用于已有正向解但包含大曲率、多 Spin 或多 O 调角的候选，不限于无解/倒车恢复。
5. O 段的 theta 恒定不等于该 theta 必须等于粗解里的 theta。通过前后 A/Spin 段和自由边界姿态共同调整，才能替换短 A–Spin–A 等结构。
6. 保持中间位置、航向、段长度和控制自由；固定真实起终点。模式与方向的离散提议由主问题搜索，连续子问题在每个提议下优化。
7. 快速筛选采用与最终成本一致的近似：路程、净空风险、连续时间估计、控制变化、方向事件。当前仅按 duration 排 safe[:6] 的方式可能漏掉高质量结构，需要有限的结构多样性名额和真实反馈。
8. 保存所有已经通过新合同的候选，精修失败不丢掉它；未满足连续转向/严格终点的旧 seed 只作初值，不能作为“安全兜底成功”。
9. 在统一预算下做结构→连续几何→时间规划→真实评价的迭代，超时保留已合格新候选。失败标签只表达局部求解或预算状态，不作为连续不可行证明。

每个候选记录：parent、结构/方向变化、几何修正、连续控制节点、切换位置、solver 状态、代理目标、真实成本分项、安全/终点/动态状态、拒绝原因与用时。

针对图 16 等情形，验收不是强制指定 O，而是在相同端任务/能力下提供 A 与稳定 O 的实际候选，比较经过同一时间规划的真实质量。若确有额外模式切换，就计入真实重配置时间；不能因为前一段已有 Spin 就假定两个方案所有转轮时间相同。

## 10. WP5：成本一致性与行为校准

### 10.1 定义先行

安全、能力和最终终点精度是硬验收，INVALID 的完整 score 必须为 null。

建议最终成本由以下无量纲项组成：

```text
J = w_clear*净空风险
  + w_shape*路径曲率及变化
  + w_control*轮角调整
  + w_oblique*不必要的 O 调角
  + w_time*T_exec/T0
  + w_length*L/L0
  + w_gear*方向换向事件
  + w_reverse*L_reverse/L0
```

说明：

- L 包含正/反全部实际平移距离，不能用起终点直线距离替代。
- T_exec 包含实际行驶、Spin 和模式切换重配置；不包含 solver 运行耗时。
- w_reverse 是轻微前进偏好，不能像目前 `reverse=2` 相对 `length=.25` 那样未经标定就强烈偏向绕行，也不能实现隐藏的字典序正向优先。
- 反复前后切换由方向事件及实际加减速时间惩罚；首段倒车不是一次方向切换。
- 稳定 O 不收“只因为用了 O”的额外罚分。
- A 同模式曲率总变差/变化率要实际进入评分，不能只写入 report。
- 全程轮角 TV/速率的指标跨模式计算，避免用极短 A 片段重置 O 调角历史；但相同物理行为不要被多个事件项重复大额惩罚。
- 模式切换真实时间已经计入 T_exec，是否再加小的事件偏好必须明确，不能沿用等效米制旧 `w_switch=2` 直接加到新无量纲 cost。
- 中心路径切线方向和车体航向是两种量。O 中 theta 恒定而 phi 改变，路径也可能弯；Spin 不通过平移曲率除以零评价。
- 连续控制曲率与轮角变化指标采用积分/物理事件定义，不能随采样数量改变。

C++ 的粗评分也要同步代理语义：检查 `action_sequence_cost_parts()`、稀疏图 `append_cost`、lattice 的逐边公式，以及其他 route DP 的内联代价，不能只改 Python 最终 evaluator。粗代理可以近似真实连续时间，但要移除未经标定的 O 标签罚与旧大额方向护栏，使用统一 profile 及明确的近似映射；各候选仍以最终独立质量为获胜依据。legacy 的旧成本保留在明确的历史对照路径中，不能悄悄混入新主链。

### 10.2 校准流程

1. 先验证所有分项数值、归一化尺度和表示不变性。
2. 选公开统一 profile，把合理候选对的其他条件尽量匹配，保存剩余差异。
3. 分别标定时间/长度、曲率/轮角、O 调角、倒车/换向偏好，再做小范围统一权重扫描。
4. 用留出场景验收，不能逐图调整权重。
5. 新 proxy 需同时检查与真实评分的排序相关性；代理目标下降不能直接证明最终质量变好。

必须形成的偏好对：

| 对照 | 预期 |
|---|---|
| 平顺 A 直达 vs 无意义额外换模 | 平顺 A 获选 |
| 大 A 绕行 vs 安全稳定短 O | 其他指标匹配或合理折衷时稳定 O 可获选 |
| 稳定 O vs 多次 O 调角 | 稳定 O 更优 |
| 单次合理连续倒车 vs 为拒绝倒车而多次 Spin/绕行 | 倒车可获选 |
| 反复前后调整 vs 同任务连续移动 | 连续移动更优 |
| 贴障短路 vs 稍长但明显更有余量 | 在声明的效率折衷内偏向净空 |
| 已达到偏好净空仍继续绕远 | 无额外净空奖励，路程/时间使其落后 |
| 宽容差终点 vs 精确终点 | 前者不得作为最终合格候选 |
| 同一连续轨迹不同采样/分段 | 分数、停车和事件计数基本不变 |

不要立即照抄某个新的固定权重表。先让两种候选都实际可行并进入池，再标定；否则调权重不会补上缺失的模式/方向结构。

## 11. WP6：窄口安全复核、地图数据与无解诊断

### 11.1 粗扫掠的自适应复核

当前 C++ `action_clear()` 用半采样位移额外膨胀 footprint，安全时可认证，但膨胀体相交不必然等于真实动作碰撞。

实现保守的三类处理：

1. 粗检查认证安全：接受为候选边。
2. 固定物理缓冲的真实姿态已明确碰撞：拒绝。
3. 仅额外采样覆盖膨胀导致相交：缩小区间/采样步长复核，直至认证安全、发现真实碰撞或达到声明的精度/预算限额。

保留 collision/margin 和基础 sweep_guard 的原物理语义，不用降低它们替代加密。A/O/Spin 使用同一原则，缓存键包含地图、姿态、动作、缓冲和精度。最终新连续几何仍需独立覆盖扫掠；粗复核不是最终安全证书。

### 11.2 P12_env2 假边界清理

先保存原始 mask、地图哈希及尺度。读取论文原始图或已有提取图，区分真实障碍与轨迹/标注残留。对明确的轴对齐墙面、立柱拟合线段/矩形/多边形后栅格化；不对整张障碍连通块一律取包围盒，避免填掉真实车位和通道。

保存前后对照图、changed_cells_mask、占据面积、自由空间连通性、关键净宽与来源说明。地图几何可以按来源记录局部修复；规划器不得识别地图名使用专属动作策略。

新旧地图分别在固定代码/成本下比较，算法新旧也在固定地图下比较。不要把地图变宽带来的成功率提升归因于优化算法。

## 12. WP7：效率、总预算与回归

### 12.1 效率实现

- 地图距离场、连续几何积分/检查、轮角函数和重复连接缓存；缓存有明确的地图/能力/控制版本键。
- 根据曲率变化、净空和误差自适应细分控制/验证节点；开放平直区不盲目增加 NLP 变量。
- 候选银行有上限，但保留模式、方向与几何的多样性；不能让同类重复候选占满全部精修次数。
- 优先保留可发布首解，再逐步改进；首解也必须满足连续运动、精确终点和独立安全合同。
- NLP 构建时间、积分/验证时间和 solver 时间都计入阶段预算。

统一请求预算建议先用全场景同一研究配置，例如 12 s，保留至少 0.5 s 的最终验收/发布余量；这是实施起点，要按数据调整，不是已测性能结论。C++ 节点数量上限不能代替墙钟 deadline。

请求入口记录开始与总 deadline，C++ 和 Python 传递已用/剩余预算并处理队列延迟。必须清楚区分 ROS 时间戳、墙钟和单调时钟；若增加消息字段，所有生产者、消费者与探针同步构建。先验证同主机计时合同，不假定两个进程的任意计时器 epoch 可直接相减。

## 15. 执行边界与容易出现的错误

- 只删除 hold、继续使用跳变曲率：不合格。
- 同模式 v 保持正值，但轮角瞬变或速度向量瞬变：不合格。
- 把所有速度显示为正或只把最终蓝车旋转到目标：不合格。
- 开放 C++ 倒车，Python/probe 仍拒绝全程倒车或要求恢复来源：未贯通。
- 用很小的前进段绕过旧全程倒车禁令：不能替代新双向合同。
- 用极短 A 插在 O 之间重置调角惩罚：指标需要跨模式物理控制检查。
- 将所有 NLP 控制节点视为模式切换节点：不合格。
- 先强制某图用 O、某图用 A，再调 cost 解释：不合格。
- 新候选精修失败就回退到同模式停车的 v1 时间轨迹并宣称成功：不合格。
- 只看离散节点不看控制插值过冲、积分误差和连续扫掠：不合格。
- 修改 P12 地图后拿旧 mask 失败率和新 mask 成功率宣布算法提高：归因不成立。
- 只满足原 .16 m/.14 rad 的 probe，宣称末端精度已修好：不合格。
- 使用仿真 profile 宣称实车动力学/跟踪已验证：不合格。
- 宣称有限候选 NLP/结构迭代就是全局最优 MINLP：不合格。
