# exp 与 expv2 算法流程总结

## 1. 结论先行

两版实验的关系不是简单的“旧版升级到新版”，而是从一个偏工程演示的在线 ROS 多模式 Hybrid A*，转向一个偏研究验证的空间规划原型：

```text
exp：在线 ROS 多模式搜索/拓扑路径 + 播放与可视化
  └─ 重点：能在地图上规划并显示 A/L/P/S 路径

expv2：可复现实验的离散空间搜索 + STC + 连续几何后端 + 独立验碰
  └─ 重点：验证固定模式序列下的几何优化和安全链路
```

两版都还没有完整解决“模式序列和连续路径同时自动最优选择”。这正是 expv3 要补上的核心。

## 2. exp：ROS/C++ 多模式 Hybrid A* 原型

### 2.1 输入与车辆模式

输入是 ROS OccupancyGrid、起点位姿和目标位姿。规划状态大致为：

```text
(x, y, θ, mode, reverse, φ, curvature, g, parent)
```

模式定义为：

| 代码 | 模式 | 当前几何含义 |
|---|---|---|
| A | Ackermann | 有限曲率前进/倒车，改变航向 |
| L | Lateral | 车身航向不变，沿车体侧向平移 |
| P | Diagonal | 车身航向不变，按 `θ+φ` 斜向平移 |
| S | Spin | 输入参考点位置不变，只改变航向；该点在 v3 中明确为车辆中心 |

这些是规划级理想模型。Ranger Mini 2.0 手册的底盘接口实际定义前后阿克曼、斜移（角度 ±90° 时横移）和自旋三种模式；因此 expv3 应将 Lateral 视为斜移模式的角度特例，而不是独立底盘模式。轮角逆解、轮速约束和真实换模暂态没有在 exp 主搜索中完整闭合。

### 2.2 默认宏观拓扑前端流程

当前配置默认 `use_macro_frontend=true`，主要流程是：

1. 把栅格地图按采样步长降采样成二维通道图。
2. 用 8 邻域 A* 搜索起点到目标的中心线，代价为距离加净空风险。
3. 对每个候选调整 clearance weight，得到不同的通道偏好/拓扑候选。
4. 用整车矩形对宏观边做密集碰撞检查。
5. 对栅格折线做 line-of-sight 简化，压缩为稀疏宏观路径。
6. 在折点用显式 Spin 改变航向，在边上先按 Ackermann/切线方向发布路径。
7. 将稀疏路径交给后续走廊/后端，或在 legacy 分支中直接稠密化后发布。

宏观前端的优点是搜索量小、能通过整车边扫检查、能产生多拓扑候选；缺点是它本身不决定真正的 4WIS 模式分配，拐点航向和边段模式是较强的先验。

### 2.3 legacy 多模式 Hybrid A* 流程

关闭宏观前端时，exp 使用真正的多模式 Hybrid A*：

1. 起点进入优先队列，启发由欧氏距离、二维障碍距离场和航向下界组成。
2. A 模式采样多个转角、正反向常曲率 primitive。
3. L/P 模式采样正反向平移，P 还采样多个 `φ`。
4. S 模式采样正负航向增量。
5. 模式切换是同位姿、零位移的显式边；切换代价根据速度、减速和舵机重构时间估计。
6. 每条运动 primitive 都用整车 OBB 沿途采样碰撞；状态哈希还记录模式、挡位和 `φ`，减少 A-L-A-L 式标签覆盖。
7. 接近目标时尝试 Ackermann Reeds–Shepp shot 或同模式平移 shot；另有 Spin→Diagonal 的解析终端 shot。
8. 达到位置/航向容差后回溯父节点，发布带 mode 标签的路径。

代价已经从单纯距离改成时间等效成本，包含倒车惩罚、转向/曲率变化、方向切换、模式进入和换模成本；Spin 成本还按距目标距离调制。

### 2.4 exp 的优点与结构性问题

优点：

- 有完整的 ROS 地图、起终点、可视化、模式标签和播放链路；
- 运动模式显式进入搜索状态，能够看到模式序列；
- 碰撞检查不是中心点检查，而是对整车外形进行沿途检查；
- 通过时间等效代价、零位移换模边和状态哈希，已经针对模式闪切做过工程修正。

主要问题：

- 解析 shot 和离散 primitive 对路径形状影响大，后端很难彻底修复不自然的几何；
- 用 switch penalty 抑制模式抖动，不能完整表达最小模式段长、轮向重构和真实暂态；
- 默认宏观前端在模式分配前已经决定了部分几何，不能称为模式与路径联合优化；
- 部分模式仍是理想几何标签，未由轮级逆运动学、舵角限位和轮速限位证明可执行；
- 当前发布/播放链路更偏演示，规划速度、控制时间和换模时间没有形成统一的轨迹接口。

## 3. expv2：可复现空间规划原型

### 3.1 研究范围和基本假设

expv2 明确把首阶段范围限定为几何规划，并假设底层控制能够完美跟踪；不实现轮级执行器动态、闭环控制和真实换模瞬态。车辆使用 `0.738 m × 0.500 m` 的矩形和 `0.810 m` 最小 Ackermann 转弯半径。expv3 采用车辆中心（前后轴中点）作为规划和输出参考点；expv2 的矩形与 Spin 固定参考点模型可沿用这一坐标约定，阿克曼曲率关系仍需按前后反向转向核对。

四种理想传播模型为：

- A：有符号弧长 `ds` 和曲率 `κ`，`|κ|≤1/Rmin`；
- P：航向不变，沿车体相对角 `φ` 平移；
- L：航向不变，固定沿 `±90°` 侧向平移；
- S：位置不动，航向增加 `dθ`。

地图使用栅格占据，规划前做占用膨胀；车辆 footprint 用密集矩形采样，短动作按不超过约 1 cm 的平移步长和约 1° 的转角步长做扫掠检查。

### 3.2 expv2 的实际流程

```text
S09 地图 + 起点/目标
        ↓
离散多模式 lattice A*
        ↓
同模式动作 shortcut / 合并
        ↓
独立 dense replay 与终点容差检查
        ↓
feature-disc Safe Travel Corridor
        ↓
固定模式连续 CasADi/IPOPT 优化
        ↓
独立 OBB raster/swept validator
        ↓
保存 JSON/CSV/图像/配置快照
```

具体来说，lattice planner 以 `(x,y,θ,last_mode)` 离散状态搜索，动作包括 A/P/L/S 的固定长度或固定航向增量。代价主要是平移长度、Spin 航向代价和模式切换惩罚；先找到达到位置/航向容差的节点，再对连续同模式动作做 shortcut，尽量用一个更长的同模式 primitive 代替许多小动作。

粗路径通过 dense replay 重放，若有任何中间姿态碰撞或终点误差超限则拒绝。通过后，SafeCorridorBuilder 用 4×2 个 feature discs 覆盖扩大后的矩形车身，对每个姿态和每个特征圆盘生成轴对齐可行框，供后端限制特征中心。

固定模式优化器把粗路径拆成更细的动作。A 优化弧长和曲率，P 优化平移长度和相对方向，L 固定侧移，S 优化航向增量；约束包括模式传播、STC、终点位置/航向容差和动作符号范围，目标包括长度、终点误差、粗路径跟踪和段内控制平滑。

现阶段 `solve_fixed_sequence` 不能改变模式的增加/删除/重排，只能优化既有模式段的几何。因此它证明的是“给定模式顺序后可以连续修正路径”，没有证明“优化器能够自己找到最佳模式顺序”。

### 3.3 expv2 已经验证的内容

根据阶段验收记录，当前已验证：

- 随机位姿和短扫掠的独立几何检查没有发现规划器漏检；
- feature discs 对名义车身及增加安全余量的车身有覆盖性检查；
- S09 的 6 条有效粗路径都完成了固定模式连续优化并通过独立整车扫掠；
- 粗路径可以作为连续后端的 warm start，后端能显著降低部分 A 段曲率抖动。

这些结果只支持“空间几何原型链路可工作”，不支持实体 4WIS 可执行性或最终算法性能结论。

### 3.4 expv2 未完成的核心问题

1. 没有自动比较不同模式序列；
2. 每个目标主要只跑单个样本，缺少扰动批次和统计区间；
3. STC 目前偏保守，走廊安全余量和最终 OBB 余量还没有完全统一；
4. 车辆参考点、最小转弯半径以及 A/P/L/S 的轮级映射仍有规划假设；
5. Chang 2026 的精确空间 MIP/MINLP 尚未实现，当前不是论文逐式复现；
6. 没有把模式切换耗时、轮角速率、轮速和控制跟踪纳入最终轨迹。

## 4. exp 与 expv2 的差异

| 对比项 | exp | expv2 |
|---|---|---|
| 主要目的 | ROS 在线演示和工程链路 | 可复现实验与模型验证 |
| 主搜索 | C++ 宏观拓扑前端/多模式 Hybrid A* | Python 理想运动 lattice A* |
| 模式决定 | 搜索中可选，但宏观前端会预先影响几何 | 搜索中可选，但后端固定已有序列 |
| 连续优化 | 有 CasADi 后端接口，默认更偏走廊/速度优化 | 已完成固定模式几何优化 pilot |
| 安全裁判 | C++ OBB 检查 | 独立 raster OBB swept validator |
| 换模 | 零位移边 + 代价，播放时 dwell | 理想瞬时切换，未建真实 transient |
| 研究结论 | 能运行和显示多模式路径 | 固定序列几何优化链路已通过 pilot |
| 尚缺 | 路径/模式真正联合优化 | 自动模式序列选择和真实执行约束 |

## 5. 对 expv3 的直接启示

- 保留 exp 的 ROS、地图、模式消息和独立碰撞接口；
- 保留 expv2 的理想传播、STC、连续优化、数据快照和 validator；
- 不再把一次 Hybrid A* 或一次 RS shot 视为最终轨迹；
- 将“多个模式序列候选”作为 expv3 的明确中间产物；
- 每个候选都走同一个连续优化和独立安全验收流程，再统一比较；
- 只有轮级能力层证明可以连续过渡的模式对，才允许使用瞬态换模；其余先停车、轮向重构、再起步。
