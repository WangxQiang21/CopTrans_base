# 新规划架构提案：空间 MIP + 整车安全分段优化

## 0. 决策摘要

**新增全文后的架构决策**：Chang et al. 2026 的完整论文已下载核读。它提出的“粗搜 + STC + 空间 MIP 联合优化路径与模式 + 分段时序轨迹 + 切换 ROI 瞬态优化”与本项目需求最吻合，现作为新架构的主参考。以下模块拆分吸收这条主线，同时保留独立整车扫掠验证，并针对车辆模式和求解资源做缩减适配。有限候选模式图是 MIP 规模过大时的对照/降级方案，不再是默认主线。

建议推翻旧的“单次 Hybrid A* 找一条路 + RS 首次连接 + 靠 switch penalty 调模式 + 后端只调速度/松走廊改几何”的组合，改成四个明确职责的层：

1. **车辆能力与地图层**：统一每种工作模式的轮级逆解、可行范围、换模动作和整车 footprint 检查。
2. **环境拓扑层**：提取可通行通道、瓶颈、泊车目标入口等锚点，生成有界的拓扑候选图。
3. **空间联合优化层**：先用拓扑引导粗搜和 STC 限定局部可行域，再用受限 MIP 联合决定离散模式、方向和连续路径几何。粗搜只供初值和 corridor，不作为最终输出。
4. **分段时序与切换层**：按 MIP 结果切分模式段，独立生成各段轨迹；对需要平滑过渡的模式对，在切换附近 ROI 解瞬态轨迹优化。对需停车才能重构的模式，显式建停车与轮向重构。最终做高精度扫掠验碰和轮级验证。

第一版只在空间层使用 MIP，时序切换保持分段局部 NLP，控制混合整数规模；若 S09 上的 MIP 计算不可接受，再切换为稀疏拓扑图 k-best 候选的备用架构。切换序列需由空间 MIP联合选择，不预先固定；切换执行则按模式对使用局部 transient optimizer 或经验证的 stop-and-reconfigure 过程。

此方案是设计提案，尚未实现或验证。

## 1. 现有方案为什么要换架构

依据 `exp/exp_plan/documant/plan/current_status.md` 与 `current_scheme.md` 的记录：

- 旧前端产生大圆弧、模式来回切换和质量不稳定；改变离散采样、启发权重和惩罚系数未根治。
- 固定最小半径 RS 连接有结构性偏好，且原始轨迹阶段已决定大量几何形状；下游仅速度优化无法修复路径形状。
- 独立几何后端曾允许 `(x,y,θ)` 偏离走廊/参考点而扫入障碍；现有整车连续碰撞闸门和“锁定已验几何”应保留为安全底线。
- 只用 `w_switch` / `flicker penalty` 抑制模式抖动，没有表达“切换要停稳、轮子需要重构、模式段有最小有效长度”的物理过程。
- 四模式简化模型与 Ranger Mini 实际可执行轮角、转向速度、轮速、舵轮重构时间之间仍需逐项对齐。Spin 尤其不能只当作任意 yaw 插值。

因此新目标不是简单加密 primitive 或重调权重，而是把“路线选择、模式段决策、连续几何、安全约束、执行时间”作为具有清楚接口的层次。

## 2. 目标和非目标

### 目标

- 支持 Ackermann、Lateral、Parallel/Diagonal、Spin 中经车辆参数核验可行的模式；术语和运动学按轮级约束定义。
- 在静态泊车地图上联合输出可解释模式序列和切换位姿。
- 各段具有连续、可执行的几何与轮向；切换按模式对处理为受约束的 ROI 过渡，或停车、重构、再起步。
- 对整车外形进行优化过程中的安全约束，以及发布前连续扫掠复核。
- 通过候选集及失败回退保留搜索完整性和可诊断性。

### 非目标（第一阶段）

- 不做端到端神经控制，不引入动态行人预测。
- 不做多车冲突消解/协同运输。
- 不做一个同时包含全局路径、离散模式、全时域动态与轮级执行器的巨大混合时空优化；先分为空间 MIP 与分段时序/切换 NLP。
- 不把 MPC 跟踪纳入首轮主干。

## 3. 分层架构与接口

```text
Occupancy map + vehicle model + start/goal
                  │
                  ▼
A. 车辆能力与 footprint 安全模型
   每模式轮级映射、模式转换可达性、整车/扫掠碰撞查询
                  │
                  ▼
B. 环境拓扑与引导信息
   净空场、窄口/交叉/泊车入口、可行终端区域
                  │
                  ▼
C. 粗搜索 + 安全走廊 STC
   只提供 MIP 初解、变量界和局部 corridor；不是最终路径
                  │
                  ▼
D. 稀疏空间 MIP
   联合优化模式序列、行驶方向、路径几何和模式内控制
                  │
                  ▼
E. 分段轨迹 + ROI 瞬态换模优化
   每个固定模式段单独优化；模式对决定 transient 或停车重构
                  │
                  ▼
F. 速度时间化 + 独立整车验证
   wheel limits / swept collision / endpoints / cost report
                  │
                  ▼
trajectory + mode schedule + validation report / failure reason
```

### A. 车辆能力与 footprint 层

创建唯一事实源 `VehicleModel`，参数包括长宽/轮距/轴距、轮角与轮速限制、转向速度、加减速度、换模式轮向过渡、安全余量。每种模式定义：轮级逆解或可行轮级集合、`propagate(state, control, dt)`、可行域与模式转换能力。每一对模式标注允许连续 transient、必须停车重构或不可达。

碰撞查询针对实际矩形/多边形 footprint。搜索期可用姿态分桶 mask 或保守圆盘加速；STC 约束至少覆盖整车 footprint 并计入误差；独立验证器做精确 OBB 与连续扫掠检查。加速近似不作为最终安全证明。

### B. 环境拓扑层

从占据栅格得到净空距离场与自由空间拓扑。抽取狭窄通道入口/出口、交叉区、车位开口和终端可行区域；每条通道标注净空、朝向范围及转弯空间。拓扑层为粗搜和 MIP 提供稀疏引导，不用不可回退的硬规则预先指定某区域只能使用某模式。

### C. 粗搜与安全走廊

使用轻量多模式搜索快速给出引导路径和模式初值。沿引导路径构造 safe travel corridors (STC)，并更新 MIP 的变量界以得到较紧的 Big-M。粗搜允许使用加权启发式，也可以次优；它不负责输出最终轨迹，不使用未经完整 footprint 验证的解析 shot 锁定最终路径。STC 构造后需由配置空间/全车外形检查确认其覆盖有效。

### D. 空间模式/路径联合 MIP

在稀疏空间离散点上建模：整数变量表示模式激活与行驶方向；连续变量表示位姿、模式控制和几何路径。约束包括模式特定离散运动学、轮级输入饱和、STC 碰撞区域、起点约束和车位终端可行区域。目标至少覆盖路径长度、模式内控制平滑、切换次数和方向反转。使用粗搜给出的模式序列作 MIP warm start，并加入模式聚类/最短段等约束抑制单点闪切。保存可行状态、求解时间、gap 与 timeout 状态。

第一阶段模式集只包含经 Ranger Mini 轮级映射验证的模式，最多 3–4 种。论文中的 ASM/DMM/ZRM 和我们现有 Ackermann/Lateral/Parallel/Spin 并非一一对应，必须重新建模。Gurobi 或其他 MIP 求解器的许可和可部署性在编码前确认；若许可/时延不满足要求，用稀疏拓扑候选图替代，而不是放松碰撞约束。

### E. 分段轨迹与瞬态换模

空间 MIP 解按连续模式切段。各段分别用连续优化生成时间轨迹，并与相邻段共享状态。切换处理依据模式对：

- 可以连续转换的模式对：在切换点附近 ROI 内优化中间模式/轮级轨迹，匹配 ROI 两端状态和控制，并约束 steering limits、车体扫掠、yaw rate、横向速度变化与时间。
- 必须停车重构的模式对：减速至零、轮向重构、确认轮级状态，再起步；重构失败则候选失败。
- 无物理可行转换的模式对：禁止在 MIP 中选择该边。

瞬态优化失败可回退到经验证的 stop-and-switch；回退也不安全时拒绝整条候选。不要把所有切换都简化成“共享位姿 + v=0”，也不要假设每种模式可以动中换挡。

### F. 时间化与独立验证

针对每段速度上限、切向/横向加速度、轮速和转向率限制做时间参数化。显式计入实际模式重构时间。发布前独立重放：整车 footprint 连续扫掠、轮角/轮速/变化率、模式转换条件、速度/加速度和终点误差。任何一项失败都拒绝发布并输出失败原因。候选排序先过滤硬约束，再比较总时间、路径长度、换模数、舒适性与净空。

### 备用：有限拓扑候选图

如果空间 MIP 在 S09 上过慢或无法部署，使用 `(anchor, heading, mode, gear)` 图生成 k-best 候选，再逐条分段优化和验证。边采用连续曲率/边界值 shooting，并在安全锚点表示显式模式重构；RS 曲线最多用于启发式或初值，不能未经几何优化和碰撞检查直接成为最终轨迹。这是计算资源不足时的备选方案，不是默认主线。

## 4. 为什么采用 Chang 2026 作为主参考

Chang et al. 的全文把模式选择与连续几何放在同一空间 MIP 中，同时把真实切换动态留给局部 ROI 瞬态优化；这比“先硬编码模式序列”或“整个长时域统一大 NLP”更贴合当前失败症状。论文也给了工程流程、Big-M 加速思路和保守停车 fallback。

不能照抄的部分是：模式定义是 ASM/DMM/ZRM，不等于当前 Ackermann/Lateral/Diagonal/Spin；其 corridor feature-point 圆盘不是我们最终安全证明；论文实车没有测试 ZRM；代码未找到且 MIP 对 Gurobi 的依赖需要评估。因此，本项目应复用其分层结构、重新推导车辆模型和 corridor，并保持独立 OBB swept-volume 验证。

## 5. 实施顺序

### Phase 0：先封住模型定义

- 从 Ranger Mini 手册/ROS 驱动核对轮角坐标、轮速符号、物理限位；分别验证四模式的逆解。
- 明确 Parallel 与 Diagonal 是同一模式还是不同定义；确认纯横移是 Lateral Ackermann 还是 crab steering。
- 测量转向重构时间与最小速度降至 0 的距离；Spin 是否允许、原地旋转时的轮角和轮速是否可达。
- 形成一组单元场景：直线、定曲率、侧移、旋转、每种模式切换。

### Phase 1：粗搜、STC 与缩减空间 MIP（先替换坏前端）

- 保留 S09 地图生成、ROS 接口和独立最终验碰。
- 实现净空场、拓扑引导粗搜和基于车体特征点的 STC；复核 STC 的 footprint 覆盖性。
- 在少量空间节点上实现模式/方向二进制变量和各模式连续几何变量的 MIP，使用粗搜提供整数初值与变量界。禁用把 RS shot 当最终输出。
- 记录求解器许可、可行解时延、gap、超时和碰撞失败。若 MIP 无解或超时，再启动有限候选图备用线。
- 第一阶段评估可行率、模式序列合理性、STC 安全性和耗时。

### Phase 2：分段轨迹和瞬态换模优化

- 按空间 MIP 的模式结果切段，各段分别构建 CasADi OCP。
- 对可连续过渡模式实现 ROI transient NLP；对 Ackermann↔Spin 等轮角限制跨越模式默认 stop-and-reconfigure，除非车辆试验确认安全连续过渡。
- 加入全车配置空间 corridor 约束，最终仍用精确连续碰撞验证器拒绝不安全输出；保留已验候选作为明确 fallback。

### Phase 3：速度和真实换模时间

- 加入轮级速度/角度约束、转向率、横向加速度、减速与重构时长。
- 用总任务时间重新排序候选；比较固定等效距离 penalty 与显式 switch-time 两种模型。

### Phase 4：消融与稳健性评估

- 基线：Ackermann-only；旧 planner（存档版）；空间 MIP + stop-and-switch；空间 MIP + ROI 瞬态优化。
- 指标：成功率、碰撞拒绝率、长度、总时间、模式段数/切换次数、最大曲率及变化、最小净空、每轮最大角度/速率、规划耗时、优化失败率。
- 地图按平行、垂直、斜位、窄口、立柱邻近分组，多起点与固定随机种子；报告失败案例，不预设“更短/更快”的结论。

## 6. 设计决策表

| 旧决策 | 新决策 | 理由 |
|---|---|---|
| 所有模式逐节点自由切换 | 空间 MIP 联合选模式；切换按模式对建模 | 抑制闪切并保留全局序列选择 |
| 单条 Hybrid A* + 首个 RS shot | 粗搜初值 + STC + 空间 MIP 联合优化 | 模式与几何一起选，粗搜不锁定最终形状 |
| 固定最小半径弧是主要运动原语 | 连续曲率/短段边界值 primitive | 让转向角和曲率在优化中连续变化 |
| 后端只优化 `v(s)` | 空间 MIP几何/模式联合优化 + 分段时序 OCP | 几何质量和离散模式决策都进入优化 |
| 参考点走廊等价于整车安全 | 配置空间安全约束 + 最终精确扫掠检查 | 保证 footprint 而非点轨迹避障 |
| 手工模式 penalty 代表换模 | 模式对专用 ROI transient 或已验证 stop-switch | 换模执行过程可行且碰撞可检 |
| 失败时无差别发布后端结果 | 每个候选带独立验证报告与失败原因 | 不让未收敛/未验碰轨迹进入执行接口 |

## 8. 已知事实与待核验项

- 已知：工作区旧方案是 Hybrid A*/多模式路径 + CasADi 后端；历史状态记录显示固定 RS 和自由切换造成质量问题；已实现整车连续碰撞发布闸门，并保留 `lock_verified_geometry: true` 安全配置。
- 已知：本地有 Bao 2025、Bao 2026、Yang 2026、ITSC 2024、ICRA 2024、4WIDS-MAPF 等 PDF 副本，见 `papers/`。
- 待核验：当前 `exp` 分支实时源代码是否仍与历史 `current_status.md` 相同；Ranger Mini 真正的轮级限位/转向速率；所有模式的真实 switch transient；Chang 论文 MIP 在 S09 上的计算规模与求解器资源需求。
- 实施前从当前代码、车辆手册和驱动映射重新测量，不以历史笔记代替运行证据。
