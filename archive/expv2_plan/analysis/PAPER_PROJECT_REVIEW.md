# 论文与项目的架构拆解

这份评审聚焦“单台 4WIS 车辆在静态泊车环境中，联合决定路径、运动模式、切换位置，并给出碰撞安全、可执行的轨迹”。论文作者结果只在各自车辆模型、地图和指标下成立。

## 一、直接相关论文

### 1. Bao et al. 2025：Multi-Modal Hybrid A*

**结构**：环境栅格/起终位姿 → 四维 Hybrid A* `(x,y,θ,mode)` → 模式内运动原语与同位姿换模边 → 模式专用多模态 Reeds–Shepp 连接/启发 → 碰撞验证 → 路径。

**优点**：把模式作为搜索状态，切换点由搜索产生，不是路径出来后再猜；模式相关连接和切换等效距离把停车、换向成本纳入排序。是可解释全局候选生成器的清楚基线。

**限制**：离散搜索分辨率和解析连接决定形状，后端可执行轨迹不在范围内；其 lateral steering 是横向 Ackermann 几何，不应误当作无侧滑纯横移；公开实现未找到。当前失败经验说明照搬“4D 状态 + RS shot + 调 cost”不会自动得到自然曲线。

**借鉴**：保留“联合搜索模式与路径”的原则；不复用固定最小半径解析 shot 作为最终轨迹，不把单个 A* 最优解当唯一后端初值。

### 2. Bao et al. 2026：从多模式路径到可执行轨迹

**结构**：模式增广 Hybrid A* 前端 → 带模式/切换感知代价和终端连接的离散路线 → 按模式分段的安全走廊轨迹优化 → 共享切换位姿、近零切换速度和重配置时间 → 速度化轨迹；论文报告了实体 4WIS 实验。

**优点**：当前文献里与本需求接口最完整的一篇：离散模式序列交给连续后端，各段动力学固定，切换处明确停车，并把安全走廊、速度与物理切换放进接口。

**限制**：后端模式序列和切换位姿来自前端，基本固定；如果走廊只约束参考点或仅用双圆保守近似，须根据我们的矩形车身重新核实；不能据论文摘要推断代码/运行时性能可复现。当前工作区已下载论文，但尚未找到公开实现。

**借鉴**：作为新方案主干：多候选离散路线 + 模式分段连续 OCP，而不是先固定一串模式后只求速度。需增强整车包络安全和失败回退。

### 3. Zhu et al. 2026：环境驱动模式筛选

**结构**：静态栅格拓扑抽取（Dijkstra/视线/折线简化）→ 通道宽度/转折属性分析 → 节点展开前按环境状态筛选可用模式 → 模式切换代价 + Hybrid A*/终端连接 → 矩形车体检查。

**优点**：把“在哪些区域某模式有用”作为搜索控制，能减少无效分支和抖动；比单靠调高 switch penalty 更结构化。

**限制**：硬剪枝可能删掉必要的逃逸路线；要有可证明/可触发的回退，否则窄场景会失去完备性。它的模式模型与车辆能力必须逐式对齐。PDF 目前不在本地资料包。

**借鉴**：将通道/目标几何用作候选排序和软偏好；只对物理不可能的模式硬剪枝，遇到无解自动放宽。

### 4. Yang et al. 2026：多模式图搜索 + 分段 QP

**结构**：离散栅格多模式节点扩展、节点多目标排序与多个目标连接候选 → 选模式序列/初始路径 → 分段 QP 平滑并周期性验碰 → 梯形速度规划。

**优点**：把模式序列、路径搜索、分段优化和速度生成拆清楚；多目标目标连接比“首次 RS 成功即收工”更稳健；本地全文可读。包含 Ackermann、Diagonal、In-place rotation 三种代表模式。

**限制**：其模型是论文特定的双虚拟轮近似；段内 QP 的可行性依赖模式边界和安全检验，不能认为普通 QP 自动处理非凸 OBB 避障。优化中放松旋转段端点约束换取平滑，实施时须检查是否与真实换模/停车过程兼容。模式数和目标函数的“最优”只限其离散代价。

**借鉴**：多候选连接、分段优化和速度规划接口；不要照搬其离散 cost 就宣称全局最优或照抄放松后的切换边界。

### 5. Chang et al. 2026：时空解耦 + MIP（全文已核）

**结构**：修改 A* 仅负责生成引导路径和模式初值 → 沿粗路径生成 safe travel corridor (STC) → 空间层 MIP 联合优化离散模式/行驶方向、车辆几何状态与模式控制 → 按模式切分路径 → 每段独立优化生成时序轨迹 → 在切换点附近 ROI 内做瞬态换模轨迹 NLP → 拼接并输出。4WID-4WIS 示例模式为 Ackermann (ASM)、Diagonal (DMM)、zero-radius rotation (ZRM)。

**MIP 具体表达**：整数变量包括各模式激活与行驶方向，连续变量包括位姿和控制；离散运动学、执行器饱和、STC 碰撞约束、初始和终端约束共同构成 MIP。目标包含路径长度、按模式定义的转向平滑、模式切换次数和方向反转。作者还给出 Big-M bounds 更新、A* 初始整数解、切割/聚类约束等加速方法。coarse A* 使用 `f=g+κh` 且 `κ>1`，明确是求快的非最优引导，不能把其本身当作全局最优保证。

**瞬态换模**：不是只在切换点强制零速。对特定 ASM↔DMM、同向连续的切换，取切换点附近 ROI，用中间模式运动学（虚拟前后轮或简化单轨两种表达）解局部轨迹优化；状态和控制在 ROI 两端与相邻轨迹段匹配，加入特征点 STC 和轮角机械限制，代价可兼顾 yaw rate、横向速度变化和耗时。触发条件不满足或优化失败则回退到 stop-and-switch。论文指出 ASM↔ZRM 这类 ICR 需要从车体外部进入内部且轮角有机械限制的切换，应先停车重构。

**优点**：这是当前最贴合本项目问题的新架构参照，全文给出流程、优化变量类别、约束类别、切换 ROI 与 fallback；比只比较固定模式序列完整。实验平台因机械风险没有实车执行 ZRM，ZRM 结果采用假设；实车验证限 ASM/DMM。仿真使用 Gurobi 求 MIP、IPOPT 求 NLP，实体闭环使用 ROS 和 pure pursuit。

**限制与适配风险**：STC 以覆盖车体轮廓的多个特征点圆盘近似，需按本车 footprint 与定位/地图误差重建，并由我们现有 OBB swept-volume validator 最终把关。其低速简化轮级/ICR 关系要用 Ranger Mini 参数重新推导；模式定义不等于本项目的 Lateral/Parallel 划分。MIP 的维度、Gurobi 许可和最坏求解时间需在 S09 上测量；作者也把降低 MIP 计算负担列为后续工作。数据声明为按请求提供，没有公开代码仓库。

**对新架构的影响**：把本文的“粗搜 → STC → 空间 MIP 模式/路径联合优化 → 分段时序轨迹 → ROI 换模优化”提升为主候选架构。第一阶段先实现缩短走廊与稀疏节点的受限 MIP，并和有限多候选路线法做计算时间/成功率对照；不要直接复刻作者未经本车验证的轮级模型，也不要取消现有独立全车安全闸门。

### 6. ITSC 2024：4WIS 泊车模式决策

**结构**：粗路径多模式搜索 → 针对模式分段的 QP 路径优化，旋转段端点约束做放松并循环安全检查 → 梯形速度规划。

**价值**：提供轻量、容易复现的前后端接口和多候选目标连接机制；本地 PDF 已下载。

**限制**：QP 对复杂非凸碰撞和整车连续扫掠的保证需独立核验；旋转/平移切换条件是否能映射到 Ranger Mini 的轮级转向暂态也要单独建模。不是连续优化模式序列的 MIP。

### 7. ICRA 2024：MIQP-MPC 模式选择

**结构**：在给定参考轨迹上，有限预测时域同时优化状态/控制与二进制 SNS/PPS 模式，使用混合整数约束表达两套运动学及轮角/速度/变化率限制，滚动执行 MPC。

**价值**：离散模式切换要用物理轮级约束描述；模式可由优化器按未来轨迹误差选择，而不只靠手工 cost。

**限制**：它解决局部跟踪控制的模式选择，不负责全局碰撞搜索或从起点生成泊车路径；两种模式定义也与当前四模式集不等价。

### 8. 4WIDS-MAPF

**结构**：高层连续空间冲突树处理多车时空冲突，低层带运动基元/模式惩罚的 Hybrid A* 负责单车路径。

**价值**：未来扩展到多车规划时，可参考高低层职责和车体尺寸冲突约束。

**限制**：当前目标是单车泊车，不应把 MAPF 复杂度先引入；共同载荷运输还需要机器人间几何和运动耦合。

## 二、相关停车/学习论文

### ParkFormer

多相机 BEV 感知/目标编码 + 行人轨迹预测 + Transformer/GRU 融合 + 离散油门、制动、转向、挡位动作的端到端模仿学习。其强项是动态障碍下的学习策略；不能直接提供硬碰撞保证、可解释模式序列或可验证换模点。适合作为数据/学习基线，不作为本次几何规划主干。

### E2E Parking Dataset

重点是 CARLA 场景/示范轨迹生成、训练和闭环评估流程，结论显示随机场景、阴影、初始位姿覆盖和训练设置会显著影响表现。可借鉴多种子、闭环测试设计；数据/感知学习与我们当前的运动学规划主问题正交。

### MERL dynamic parking

双向搜索树/BIAGT 一类分治规划框架，上层调度与单车避碰规划分层；重点在动态环境和多个车辆协同/通行效率。可借鉴全局任务调度与局部规划职责分离；不是 4WIS 模式序列解法。

### 其余邻近论文（HOPE、MultiPark、Improved A*、Liu 4WD）

分别可用于强化停车策略/网络、数据或场景覆盖、搜索启发，以及轮级转向控制的比较。它们不是同一任务设定，实验结果不能与静态单车 4WIS 模式规划直接横比。最终引用前须逐份依据本地 PDF 首页核作者、年份、题名和 DOI；历史笔记中存在题名或年份混用风险。

## 三、开源项目架构

### AWSPlanning / C-AWS

前端在 `(x,y,θ)` 上带车轮速度/角度状态，以瞬时运动中心/角速度采样可行连续全轮转向动作；搜索代价包含车轮速度和转向变化；后端 CasADi/IPOPT、RK4 和可变时间步优化轮级约束。toy optimizer 已成功运行，但没有完整验证 ROS+Isaac 仿真。其“动作连续”与本项目的“有限工作模式”不同：适合借鉴轮级约束、动态后端和代码组织，不能直接当作所需离散模式规划器。

### MPPI Swerve Drive ROS

ROS/Gazebo 局部控制器并行/切换 3D 与 4D 的 MPPI 采样空间，以跟踪误差选表示维度；它不是切换 Ackermann/crab/spin 等物理模式。可参考滚动采样控制与 ROS 接口，不能作为全局路径搜索替代。

### OTC-Planner

Hybrid A* 生成泊车粗路径，定向旅行走廊压缩可行空间，CasADi/IPOPT smoother 进行连续几何平滑；项目代码可作工程对照。必须检查当前分支的车体模型、走廊构造和碰撞约束。对 4WIS 改造时，模式序列须锁定在优化区间内，切换点显式分段，整车旋转扫掠必须加入约束或严格验证。

### Apollo Open Space

开放空间规划的搜索/迭代平滑/速度优化分层，反映了粗解、几何优化、速度规划的职责拆分和工程 fallback 思路。它的车辆运动学和工程体量均不同，应该借架构原则和评估边界，不整体移植。

### 两个“4WIS”仓库的边界

`balmung08/4WIS-Hybrid-Astar-Safe-Corridor-Optimization` 的 README 以双向 Ackermann 为主；`githubGzj/Kinodynamic-Planning-System-for-4WISD-Robots` 标为后续开放。它们目前不能作为已验证的多模式完整实现。
