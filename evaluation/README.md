# 规划结果评估

这里保存可提交的评估模板和简短评估报告；ROS 原始日志、JSON、地图副本和图片放在仓库外的归档目录：

`/home/wq/whut_thesis/expv3_experiment_archive/`

每次完成测试后，复制 `TEMPLATE.md` 为 `YYYYMMDD_测试名称.md`，填入真实运行数据，并在报告中链接对应原始结果目录和图片。不要把整批 ROS 原始输出复制进仓库。

评估顺序固定为：

1. **可用性**：规划是否成功、终点误差、独立扫掠碰撞检查、地图/起终点是否正确。
2. **效率**：规划耗时和执行时长；同时记录模式切换次数、倒车长度及低速区间。
3. **路径质量**：最小净空、路径长度、模式序列和局部绕行情况。
4. **可复核材料**：地图预览、轨迹叠加图、走廊局部图、原始 JSON 与日志。

只有安全与终点验收通过的运行才进入时间和路径质量比较。跨后端比较时记录各自时序契约；契约不同的执行时长不能直接当作同口径排名。
