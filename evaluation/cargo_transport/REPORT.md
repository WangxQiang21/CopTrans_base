# 货物中心楔形编队：配置、面积与交互验证

日期：2026-11-11。用户指定的运输合同取代此前默认的横排编队及独立车体航向假设。

## 合同与当前完成范围

货物参考点为 F=(0,0)，car1=(0,1)、car2=(-1,0)、car3=(1,0) m。
世界坐标中心为 p_i=p_F+R(psi_F)r_i，全部车体 theta_i=psi_F。
车间距离分别 sqrt(2)、sqrt(2)、2 m，运动中不改变。
现有车辆尺寸 0.738×0.500 m。

已完成：默认楔形、车货同航向硬审核、地图尺度、货物起终点输入、静止队形预览、
失败状态显示、共享回放时钟从发布时刻开始、原单车入口保留。
当前可运行固定货物航向的平移运输。完整货物转向尚未完成：通用 4WIS 模型扩展待用户选择。

现有 A/O/S 中，O 的车体角速度为零，S 的车辆中心速度为零，A 的中心速度必须沿车头。
同航向刚性编队的车体坐标速度满足 v_i=R(-psi_F)v_F+omega_F J r_i。
三车的 x 偏移为 0、-1、1，因此编队旋转时它们的横向速度不相同。
无法让这三车都由当前 A/O/S 实现同航向的刚性旋转。
后端明确返回 CARGO_ROTATION_REQUIRES_GENERAL_4WIS，不能通过改变车体朝向来绕过合同。

## 面积及地图尺度

扫掠面积依赖整条路径，并不存在适用于任意轨迹的单一面积。以下旋转扫掠特指绕货物原点整圈旋转。
不含安全膨胀；货物实体尺寸未给出，因此只计算三辆车，未宣称货物外形碰撞安全。

| 几何量 | 单车 | 指定三车编队 |
|---|---:|---:|
| 车体占用并集 | 0.369 m² | 1.107 m² |
| 车体凸包面积 | 0.369 m² | 3.107 m² |
| 同航向包围盒 | 0.738×0.500 m | 2.738×1.500 m |
| 包围盒面积 | 0.369 m² | 4.107 m² |
| 完整旋转的实际车体扫掠并集 | 0.624112 m² | 4.833340 m² |
| 编队旋转外包圆面积 | — | 6.084200 m² |

单车旋转半径 sqrt(0.369²+0.25²)，扫掠为实心圆。
编队实际旋转扫掠为圆环，内半径 1-0.369=0.631 m，
外半径 sqrt(1.369²+0.25²)=1.391640 m，
面积 pi*((1.369²+0.25²)-0.631²)=4.833340 m²。
凸包绕原点的完整扫掠为外包圆，区别于三车车体的实际并集。
数值可由 `python3 tools/transport_footprint.py` 重算，见 [footprint.json](footprint.json)。

地图是长度量，默认倍率按同航向包围盒两轴的最大增长确定：
max(2.738/0.738, 1.5/0.5)=3.710027，向上取 3.75。
该比例用于扩大实验空间，不是所有通道必然可通过的证明。

## 用户操作

```bash
cd /home/wq/whut_thesis/expv3_multi
bash run_demo.sh --map map04 auto_goal:=false
# 2D Pose Estimate：货物起点与方向，立即显示三车。
# 2D Nav Goal：货物终点与方向，所有车辆按固定偏移生成。
# 当前 A/O/S 下，起终点货物航向须一致；改变货物航向会明确拒绝。

bash run_demo.sh --map map16 --scale 3.75 auto_goal:=false
bash run_demo.sh --map map04 --dry-run
bash run_demo.sh --single --map map04
```

省略 `auto_goal:=false` 时沿用单车流程，读取地图预设货物起终点。
预设若改变货物航向，当前模型会返回上述显式失败码。
单车人工采集仍通过 `--single --collect-data`；编队未接入该单车标注网页。

## 修复的交互与集成问题

- 地图 `/start_pose` 作为货物初始位姿；手动起点优先，失败后不会自动跳到尚未到达的上次目标。
- 新请求清除旧可执行轨迹，但显示独立静止队形，标注 STATIC/no executable trajectory。
- 前端失败通过 `/formation/status` 显示；缓存按 plan_id 关联，处理状态先于请求到达的顺序。
- 回放 timer 与订阅回调串行保护，防止清理后再次发布旧动画帧。
- 地图之前到达的有效请求暂存，地图就绪后执行。
- 几何搜索到达粗容差附近后，补上经整车扫掠审核的精确平移与旋转连接，解决最后一段无法同时消除位置/角度残差的问题。
- 编队 launch 从正式发布时间设置共享时间原点，避免把求解耗时当作已经执行的轨迹时间。
