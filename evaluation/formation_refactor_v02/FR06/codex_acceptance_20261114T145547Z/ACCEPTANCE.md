## 4. 报告的解释性修正（不新增开发返工）

以下以本复核结论和原始JSON为准，论文整理时应采用正确口径；不影响核心实验成立。

1. **多出的时间不是额外轮系设置。** 参考29.9552947533秒，自主路线33.0244944272秒，多3.0691996739秒。两者setup均4段、总计7.3221272304秒，差为0；A、S时长也相同。差额全部来自O平移由两条2m边变为四条1m边后的重复加减速/停车。原REPORT第5节“额外inter-edge setup dwells”归因不成立。
2. **净空必须注明测量对象。** 0.129119232m是连续名义距离带的车体边界净空，扣0.05m后的0.079119232m同属该名义几何；不是已计算的实际占用栅格最小距离。独立闭式复算`1.4-(sqrt(3.25²+0.369²)-2)`得到相同名义值。地图上的安全性由FR02实际栅格扫掠审核证明，不能把名义值冒称栅格精确净空；时间/边界采样也不是一般连续全域极值证明。
3. **部分手填碰撞计时有小偏差。** 三个tight run原始collision_s分别5.473642、5.423574、5.464119秒，与Markdown部分数值不完全一致；experiment_summary与原始JSON一致，使用机器记录。
4. **图像只证明已捕获的时段。** 捕获从播放约12秒开始，S运动约11秒已结束，故早期图像能显示S对齐后的车头，不能单凭它们声称录到了完整自旋过程。模型/审核包含S，真实回放日志覆盖完整时间轴，但图像采集不是全程视频。

本轮证明了至少一个较紧窄角的刚性规划/时间审核/真实回放；同时保留一个存在参考可行解却未自主找到的较宽场景。它不支持全图成功率、通道越窄越容易、普遍完备性/最优性或“非零pivot提高成功率”的因果结论。2.6m参考失败也不证明该环境数学无解。
