## 3. 公共时间律

```text
tau = t/T
h   = 10*tau^3 - 15*tau^4 + 6*tau^5
h1  = 30*tau^2*(1-tau)^2
h2  = 60*tau - 180*tau^2 + 120*tau^3
h3  = 60 - 360*tau + 360*tau^2
s=S*h, w=S*h1/T, a=S*h2/T^2, j=S*h3/T^3

速度 v=Q*w, 角速度 omega=H*w
加速度 p_ss*w^2 + p_s*a, jerk p_sss*w^3 + 3*p_ss*w*a + p_s*j
yaw_accel=H*a+H_s*w^2, yaw_jerk=H*j+3*H_s*w*a+H_ss*w^3
lateral_accel=abs(C)*v^2
wheel: Ew=m^2+n^2, delta=atan2(n,m), wheel_speed=sqrt(Ew)*v
steer_rate=delta_s*w, steer_accel=delta_ss*w^2+delta_s*a
```

T 选择：`T0=1 s`，对整段每个 Hermite 段和对应时间区间使用 G1 外扩区间界，按 1/2/3 阶候选 `(U/limit)^(1/order)` 取最大；`selected=required*1.01`；最多 8 次 1.05 重缩放；工程预算 600 s。本运行所有运动实例 `rescalings=0`。
