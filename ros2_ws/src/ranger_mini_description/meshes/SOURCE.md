# AgileX Ranger Mini 2.0 meshes

`ranger_base.zip`, `fl.dae` and `fr.dae` are the original Git blobs from
AgileX `ugv_gazebo_sim` commit `27633a956c845903ee630538afeb17fe70afdd84`,
directory `ranger_mini/ranger_mini_v2/meshes`. The upstream description
manifest identifies its license as BSD. The archive contains `ranger_base.dae`
and is extracted at build time.

`paint_meshes.py` generates the white, orange, and blue display meshes at
build time. The variants share the same chassis and wheel meshes and keep
the original vertex positions.

[Upstream model files](https://github.com/agilexrobotics/ugv_gazebo_sim/tree/27633a956c845903ee630538afeb17fe70afdd84/ranger_mini/ranger_mini_v2)
